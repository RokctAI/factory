# VibeVoice reference audio samples

Three real VibeVoice outputs, checked in so anyone evaluating the engine can hear
it without re-running inference. All three are 24 kHz mono 16-bit WAV.

| File | Model | Duration |
| :--- | :--- | :--- |
| `single_speaker.wav` | VibeVoice-1.5B | 13.73 s |
| `two_speaker_dialogue.wav` | VibeVoice-1.5B | 21.60 s |
| `realtime_0.5b_sample.wav` | VibeVoice-Realtime-0.5B | 4.00 s |

## How they were generated

Generated 2026-08-12 on **CPU only** — 4-core Intel Xeon (Cascade Lake), 15 GB RAM,
no GPU — running Ubuntu 24.04 and Python 3.11.15.

**Code**: the community fork <https://github.com/vibevoice-community/VibeVoice> at commit
`631804b9c1f042e381207fe87c54603fe6accbc1`. Microsoft removed the TTS inference code from
<https://github.com/microsoft/VibeVoice> on 2025-09-05 and force-reset the history, so
upstream no longer ships it — the fork is the only source for the inference path.

**Weights** (both MIT-licensed and ungated on Hugging Face):

- `microsoft/VibeVoice-1.5B`, revision `c00898d257e6b46004e3e2866a47534085fb685a` — used
  for `single_speaker.wav` and `two_speaker_dialogue.wav`.
- `microsoft/VibeVoice-Realtime-0.5B`, revision `6bce5f06044837fe6d2c5d7a71a84f0416bd57e4` —
  used for `realtime_0.5b_sample.wav`.

**Stack**: torch 2.13.0+cpu, transformers 4.51.3, float32, `sdpa` attention, no flash-attn.

**Settings**: stock defaults — `cfg_scale` 1.3, 10 DDPM inference steps. Voices are the
fork's bundled demo prompts (`Alice`, `Frank` from `demo/voices/`). No real person's voice
was cloned.

**Command**:

```bash
python demo/inference_from_file.py \
  --model_path microsoft/VibeVoice-1.5B \
  --txt_path <txt> \
  --output_dir <dir> \
  --speaker_names Alice Frank
```

## Measured performance

RTF here is generation time divided by audio duration, so lower is faster and anything
above 1.00x is slower than real time.

| Sample | Audio | Generation | RTF | Peak RSS |
| :--- | ---: | ---: | ---: | ---: |
| Single speaker (1.5B) | 13.73 s | 80.5 s | 5.86x | 12.3 GB |
| Two speaker (1.5B) | 21.60 s | 155.8 s | 7.21x | 12.5 GB |
| Realtime-0.5B | 4.00 s | 8.0 s | 1.99x | 7.5 GB |

## Caveats

**Output is quiet.** Roughly 10 dB below where it should sit — about **-26.5 dBFS RMS**,
versus -16.0 dBFS for the source voice prompt. Normalize before using any of this audio
for anything.

**The advertised watermark and AI disclaimer are not present.** The VibeVoice model card
claims every synthesized file carries an audible "This segment was generated by AI"
disclaimer plus an imperceptible watermark. Neither is in the open-weights inference path
— no such code exists anywhere in the stack. Do not rely on it for provenance.

**Licensing conflict, unresolved.** The code and weights are MIT, but the model card
restricts use to research purposes and bars voice impersonation without explicit recorded
consent, disinformation, and real-time voice conversion. MIT and those restrictions do not
sit comfortably together, and which one governs is not settled here. This is worth legal
review before any production use.
