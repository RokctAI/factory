## Question (2 marks)

Classify EACH of the temporary base levels in sketch A as either natural or human-made. (2 x 1)  (Two longitudinal river profiles. Sketch A - ungraded profile from source to mouth: a waterfall over resistant rock near the source, a dam with a dashed line marked temporary base level, and a dashed line at sea level marked permanent base level. Sketch B - smooth, concave graded profile from source to mouth with permanent base level at the sea.)

## Method

classification

## Memo working

A temporary base level is any level, above the sea, below which the river cannot erode for a time. The waterfall forms over resistant rock, so it is natural (1). The dam is built by people, so it is human-made (1).

## Answer (per marking guidelines)

Natural: Waterfall (1). Human-made: Dam (1).
