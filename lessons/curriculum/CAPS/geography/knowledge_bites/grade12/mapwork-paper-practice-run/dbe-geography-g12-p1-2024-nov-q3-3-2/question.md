## Question (1 mark)

Geographical Information Systems (GIS): The reference of the topographical map represents (spatial/attribute) data. (1 x 1)

## Method

gis concepts

Spatial data records where things are; attribute data records information about them. The map reference (the sheet's identifying and descriptive information) describes rather than locates, so it is attribute data.
