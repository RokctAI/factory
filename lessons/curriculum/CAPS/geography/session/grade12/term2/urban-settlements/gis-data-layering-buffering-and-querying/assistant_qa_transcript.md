**Mandy:** Before you move on — a few questions that come up a lot with this topic. The big one first: spatial versus attribute data still trips people on the day. Is there a test that never fails?

**Tutor:** There is, and it fits in one question: could you draw it, or would you have to write it? Anything you would draw — the line of the road, the outline of the dam, the dot of the trig beacon — is spatial data, because it carries position and shape. Anything you would have to write — the road's number, the dam's name, the farm's size in hectares — is attribute data, a fact pinned to the feature. The exam's favourite version prints a number on a road and asks what kind of data the number is. Learners see the road, think position, and answer spatial — but the question asked about the number, not the road. The number describes; it does not locate. So run the test on the exact thing the question names, not on the feature it sits on. Draw it: spatial. Write it: attribute. That distinction, applied to the right noun, is the whole mark.

***

**Mandy:** Next one: buffering and data layering blur together for a lot of the class. Both get drawn as shapes on the map, so how do you keep them apart under pressure?

**Tutor:** Separate them by what they are for. Data layering is about storage and display: information is kept in separate themed sheets — drainage on one, roads on another — stacked over the same coordinates so you can view any combination. Nothing in a layer makes a decision; it just holds a theme tidily. Buffering is about protection and decision: it draws a zone of chosen width around one feature so the inside can be ruled differently from the outside — no houses within the flood strip, no foundations near the sinkholes. So ask: is the question about organising many kinds of information, or about keeping something at a distance from something else? Organising is layering. Distance and protection is buffering. And notice the shapes betray the same difference: a layer covers the whole map, edge to edge, while a buffer clings to one feature — a circle round a point, a corridor along a line. Whole map, layering; zone around one thing, buffering.

***

**Mandy:** The redraw question scares people — combine the layers into one frame. What loses marks there, and what is the safe method?

**Tutor:** The mark-loser is repositioning. Learners treat it as a design task and tidy the features up — sliding the stream aside so it does not cross the woodland, shrinking a patch to fit. But the whole premise of layering is that every sheet shares the same coordinates, so each feature has exactly one legal position in the combined frame: the position it already occupies in its own sketch. The safe method is mechanical. Take the layers one at a time. For each feature, note where it sits in its frame — which corner, which third, how far from which edge — and copy it into the same place in the answer frame. If two features overlap when stacked, draw the overlap; overlap is not an error, it is the point. Then check you have carried every feature across, because the marking is one mark per correctly placed layer. No artistry, no rearranging, no leaving anything out. It is copying with care, and copying with care is full marks.

***

**Mandy:** Last one: some of the class have never touched GIS software, and it makes the whole topic feel unreal. Do you need a computer to answer these questions?

**Tutor:** No — and the syllabus itself proves it, because it teaches a paper version of the system. Take a base map and lay sheets of tracing paper over it: trace only the rivers on one sheet, only the roads on another, only the buildings on a third. Stack any two and you have performed data layering. Draw a line one centimetre from the stream on its sheet and you have buffered it — at fifty thousand to one, that centimetre is a five-hundred-metre protection strip. Flip through the sheets asking which open land lies outside the buffer and below the steep contours, and you have run a query with your eyes. Every concept the examiners test — layers, buffers, queries, integration — exists complete in that stack of tracing paper; the computer only adds speed, storage and arithmetic. So build the paper version once at your desk and the vocabulary stops being abstract: you have not read about a GIS, you have operated one.
