## Question (1 mark)

For the same weight and push-up data (Weight (in kg) (x): 34, 32, 40, 27, 33, 28, 27, 55, 39, 44, 30, 57, 28, 32, 31. Number of push-ups per minute (y): 26, 21, 6, 20, 16, 26, 23, 7, 18, 14, 17, 8, 28, 25, 20.), write down the correlation coefficient.

## Memo working

From the calculator's regression output for the same data, r = -0,7979..., which rounds to -0,8. This confirms a strong negative relationship: the heavier a player, the fewer push-ups per minute.

## Answer (per marking guidelines)

r = -0,8
