## Question (2 marks)

After how many seconds was the torpedo at 104 m below sea level for the second time?

## Method

quadratic pattern symmetry

## Memo working

By symmetry about n = 19: (n + 3)/2 = 19; n + 3 = 38; n = 35

(Memo note: Alternative memo method solves -n^2 + 38n - 1 = 104: n^2 - 38n + 105 = 0; (n - 35)(n - 3) = 0; n = 35.)

## Answer (per marking guidelines)

n = 35 (seconds)
