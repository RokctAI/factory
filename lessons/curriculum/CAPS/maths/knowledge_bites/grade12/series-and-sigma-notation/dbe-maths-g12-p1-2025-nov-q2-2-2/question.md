## Question (5 marks)

Calculate the value of k.

## Method

arithmetic series solve first index

## Memo working

Number of terms n = 118 - k; last term T117 = 467; S = (118 - k)/2 [4k - 1 + 467] = 26 675; 26 675 = (118 - k)(2k + 233); 2k^2 - 3k - 819 = 0; (k - 21)(2k + 39) = 0; k = 21 (k = -39/2 rejected)

(Memo note: Alternative memo methods: (118-k)/2 [2(4k-1) + (118-k-1)(4)] = 26 675; or S117 = 27 495, S_(k-1) = 27 495 - 26 675 = 820 -> 2n^2 + n - 820 = 0 -> n = 20, k - 1 = 20 -> k = 21.)

## Answer (per marking guidelines)

k = 21 (k = -39/2 rejected)
