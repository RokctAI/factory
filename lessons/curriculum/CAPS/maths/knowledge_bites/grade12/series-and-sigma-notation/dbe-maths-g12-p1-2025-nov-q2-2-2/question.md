## Question (5 marks)

Calculate the value of k. (Given: Sum from p=k to 117 of (4p - 1) = 26 675)

## Method

arithmetic series solve first index

## Memo working

The sum runs from p = k to p = 117, so the number of terms is n = 118 - k. The first term is 4k - 1 and the last term is T117 = 4(117) - 1 = 467. Using S = n/2 (first + last): (118 - k)/2 [4k - 1 + 467] = 26 675, so 26 675 = (118 - k)(2k + 233). Expand and simplify: 2k^2 - 3k - 819 = 0. Factorise: (k - 21)(2k + 39) = 0, so k = 21 (k = -39/2 rejected because k must be a positive integer index). (Memo alternatives: (118-k)/2 [2(4k-1) + (118-k-1)(4)] = 26 675; or S117 = 27 495 and S_(k-1) = 27 495 - 26 675 = 820 -> 2n^2 + n - 820 = 0 -> n = 20, so k - 1 = 20 -> k = 21.)

## Answer (per marking guidelines)

k = 21 (k = -39/2 rejected)
