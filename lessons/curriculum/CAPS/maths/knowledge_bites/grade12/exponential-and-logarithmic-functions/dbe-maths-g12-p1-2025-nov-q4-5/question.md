## Question (3 marks)

Draw the graph of f^(-1) on the set of axes provided in the ANSWER BOOK. Clearly indicate the intercepts with the axes, the coordinates of ONE other point and the asymptotes. (f^(-1)(x) = (1/3)^x)

## Method

sketch exponential graph

## Memo working

Memo sketch awards: decreasing exponential shape with asymptote y = 0; y-intercept (0 ; 1); any other point (e.g. (-1 ; 3)). Reasoning: f^(-1)(x) = (1/3)^x has base between 0 and 1, so it decreases from left to right, lying entirely above the x-axis. At x = 0 it gives (1/3)^0 = 1, the y-intercept (0 ; 1); there is no x-intercept because the curve never reaches y = 0. A convenient second point is (-1 ; 3), since (1/3)^(-1) = 3.

## Answer (per marking guidelines)

Decreasing exponential through (0 ; 1) and (-1 ; 3) with horizontal asymptote y = 0
