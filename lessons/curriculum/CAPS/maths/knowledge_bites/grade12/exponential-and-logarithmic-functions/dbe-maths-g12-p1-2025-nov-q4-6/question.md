## Question (2 marks)

The graph of h is obtained when f^(-1) is translated 5 units to the right. Determine the y-values of h where x > 4.  (f^(-1)(x) = (1/3)^x)

## Method

translate exponential evaluate range

## Memo working

Translating 5 units right gives h(x) = (1/3)^(x-5). At x = 4: h(4) = (1/3)^(-1) = 3, so (4 ; 3) lies on h. The curve is a decreasing exponential with asymptote y = 0, so for x > 4 the y-values drop from 3 towards 0 without reaching either: 0 < y < 3.

## Answer (per marking guidelines)

0 < y < 3  OR  y ∈ (0 ; 3)
