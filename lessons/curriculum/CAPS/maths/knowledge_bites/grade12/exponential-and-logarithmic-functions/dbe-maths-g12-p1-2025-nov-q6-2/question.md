## Question (5 marks)

Graph g intersects the horizontal asymptote of graph f at x = 1 and the graph f at x = 3. Graphs f and g also intersect on the y-axis. Determine the equation of f.

## Method

solve hyperbola parameters from conditions

## Memo working

x-intercept of g is x = -c, which is also the vertical asymptote of f, so p = c; g meets the horizontal asymptote at x = 1, so q = g(1) = 1 + c; f(x) = a/(x + c) + 1 + c. Intersection on y-axis (0 ; c): c = a/c + 1 + c -> a = -c; point (3 ; 3 + c) on f: 3 + c = -c/(3 + c) + 1 + c; 9 + 6c + c^2 = -c + 3 + 4c + c^2; 3c = -6; c = -2; a = 2; q = -1; f(x) = 2/(x - 2) - 1

(Memo note: Alternative memo method finds a = 6 + 2c from the point (3 ; 3 + c) first, then uses the y-axis intersection (0 ; c) to get c = -2, a = 2, q = -1.)

## Answer (per marking guidelines)

f(x) = 2/(x - 2) - 1
