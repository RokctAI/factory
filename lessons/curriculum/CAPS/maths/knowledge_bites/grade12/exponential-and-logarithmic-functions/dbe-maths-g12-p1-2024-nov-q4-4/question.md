## Question (3 marks)

It is further given that C is a point on f at y = 19/8, where f(x) = (2/3)^x - 1. Determine the coordinates of C', the image of C, when C is reflected about the line y = x.

## Method

solve exponential then reflect

## Memo working

Find C by solving 19/8 = (2/3)^x - 1, so (2/3)^x = 27/8. Since 27/8 = (3/2)^3 = (2/3)^(-3), the exponents give x = -3, so C(-3 ; 19/8). Reflection about the line y = x swaps the coordinates: C'(19/8 ; -3)

## Answer (per marking guidelines)

C'(19/8 ; -3)
