## Question (4 marks)

Prove, with reasons, that: PW = QE.PZ/sqrt(QR.QZ) (From QUESTIONS 11.2.1 and 11.2.2: PR = PW.QR/QE, PQ^2 = RQ.QZ, and ΔPQZ ||| ΔRQP.)

## Method

combine similar triangles

## Memo working

From the similarity ΔPQZ ||| ΔRQP, corresponding sides give PQ/RQ = PZ/PR, so PR = QR.PZ/PQ. But QUESTION 11.2.1 proved PR = PW.QR/QE. Set the two expressions for PR equal: PW.QR/QE = QR.PZ/PQ. Cancel QR from both sides and solve for PW: PW = QE.PZ/PQ. Finally, from QUESTION 11.2.2, PQ^2 = RQ.QZ, so PQ = sqrt(RQ.QZ). Substituting gives PW = QE.PZ/sqrt(QR.QZ).

## Answer (per marking guidelines)

PW = QE.PZ/sqrt(QR.QZ)
