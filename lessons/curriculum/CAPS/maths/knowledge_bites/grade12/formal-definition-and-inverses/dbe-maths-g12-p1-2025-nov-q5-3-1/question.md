## Question (2 marks)

Determine the values of x for which g(x) ≤ f(x)

## Method

graph inequality reading

## Memo working

Between the vertical asymptote x = 3 and the intersection point D(5 ; 6)

## Answer (per marking guidelines)

3 < x ≤ 5  OR  x ∈ (3 ; 5]
