## Question (6 marks)

Calculate the length of MT.

## Method

x intercepts distance

## Memo working

f: -(1/2)x^2 + 3x + 7/2 = 0 -> x^2 - 6x - 7 = 0; (x - 7)(x + 1) = 0; M(-1 ; 0); g: 0 = -4/(x - 3) + 8 -> -8x + 24 = -4 -> x = 7/2; T(7/2 ; 0); MT = 7/2 + 1 = 9/2 = 4,5

## Answer (per marking guidelines)

MT = 9/2 = 4,5
