## Question (3 marks)

For which values of x is f(x) >= 0?

## Method

hyperbola inequality

## Memo working

x-intercept: -3/(x-1) - 2 = 0; -3 = 2x - 2; x = -1/2; f >= 0 between the x-intercept and the vertical asymptote

## Answer (per marking guidelines)

x ∈ [-1/2 ; 1)  OR  -1/2 <= x < 1
