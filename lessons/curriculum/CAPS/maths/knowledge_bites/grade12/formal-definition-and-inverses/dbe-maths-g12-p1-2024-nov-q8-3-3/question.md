## Question (3 marks)

Given: f(x) = -6x^2. Determine the equation of f^(-1) for f^(-1)(x) <= 0. Write your answer in the form y = ...

## Method

inverse of parabola

## Memo working

Start from y = -6x^2 and swap x and y to build the inverse: x = -6y^2. Solve for y: y^2 = -x/6, so y = ±sqrt(-x/6). Since the question requires f^(-1)(x) <= 0, take the negative branch: y = -sqrt(-x/6). The inverse is only defined where -x/6 >= 0, that is for x <= 0.

## Answer (per marking guidelines)

y = -sqrt(-x/6), x <= 0
