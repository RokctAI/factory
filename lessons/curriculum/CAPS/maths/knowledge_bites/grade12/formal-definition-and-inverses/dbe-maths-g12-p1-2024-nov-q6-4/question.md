## Question (5 marks)

Given: k(x) = f(x + m) = -x^2 - 2mx - m^2 + 4x + 4m + 5. Determine the value of m such that g is a tangent to k.

## Method

tangency condition derivative

## Memo working

k'(x) = -2x - 2m + 4 = 2 (gradient of g); x = 1 - m; set k(1-m) = g(1-m): -(1-m)^2 - 2m(1-m) - m^2 + 4(1-m) + 4m + 5 = 2(1-m) + 2; -2m - 4 = 0; m = -2. Answer only: 0/5

(Memo note: Alternative memo methods: (1) equate k and g, set discriminant of x^2 + (2m-2)x + m^2 - 4m - 3 = 0 to zero -> 8m + 16 = 0 -> m = -2; (2) f'(x) = 2 at x = 1, point (1 ; 8), horizontal translation 2 units right -> m = -2.)

## Answer (per marking guidelines)

m = -2
