## Question (3 marks)

Given f(x) = x^3 - 8x^2 + 5x + 14. For which values of x is f concave down?

## Method

second derivative concavity

## Memo working

Concavity is decided by the second derivative. f'(x) = 3x^2 - 16x + 5, so f''(x) = 6x - 16. The graph is concave down where f''(x) < 0: 6x - 16 < 0, so x < 8/3. (Alternative memo method: the point of inflection lies midway between the turning points, x = (1/3 + 5)/2 = 8/3, and the cubic with positive leading coefficient is concave down to the left of it.)

## Answer (per marking guidelines)

x < 8/3
