## Question (3 marks)

For which values of x is f concave down?

## Method

second derivative concavity

## Memo working

f''(x) = 6x - 16 < 0 -> x < 8/3

(Memo note: Alternative memo method: midpoint of turning points x = (1/3 + 5)/2 = 8/3; concave down for x < 8/3.)

## Answer (per marking guidelines)

x < 8/3
