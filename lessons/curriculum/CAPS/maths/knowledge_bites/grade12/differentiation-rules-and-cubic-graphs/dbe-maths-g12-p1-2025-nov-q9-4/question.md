## Question (6 marks)

Given f(x) = x^3 - 8x^2 + 5x + 14. For which values of t will y = -11x + t intersect f at 3 distinct points?

## Method

tangency bounds for three roots

## Memo working

A line of fixed gradient -11 cuts the cubic in three distinct points exactly when it lies strictly between the two positions where it is tangent to the curve. Find the tangency points from f'(x) = -11: 3x^2 - 16x + 5 = -11 gives 3x^2 - 16x + 16 = 0, which factorises as (x - 4)(3x - 4) = 0, so x = 4 or x = 4/3. At x = 4: f(4) = -30, and the tangent line -11x + t through (4 ; -30) gives t = -30 + 44 = 14. At x = 4/3: f(4/3) = 238/27, giving t = 238/27 + 44/3 = 634/27 = 23 13/27 = 23,48. Three distinct intersection points occur for t strictly between these bounds.

## Answer (per marking guidelines)

14 < t < 634/27
