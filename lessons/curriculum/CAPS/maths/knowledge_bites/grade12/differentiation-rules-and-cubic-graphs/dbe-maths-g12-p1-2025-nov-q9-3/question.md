## Question (4 marks)

The coordinates of B are (2 ; 0). Use the graph to determine the values of x for which f(x) . f''(x) < 0

## Method

sign analysis product

## Memo working

x-intercepts of f: (-1 ; 0) and (7 ; 0) (with B(2 ; 0)); f > 0 with f'' < 0 on (-1 ; 2); f < 0 with f'' > 0 on (8/3 ; 7)

## Answer (per marking guidelines)

-1 < x < 2 or 8/3 < x < 7
