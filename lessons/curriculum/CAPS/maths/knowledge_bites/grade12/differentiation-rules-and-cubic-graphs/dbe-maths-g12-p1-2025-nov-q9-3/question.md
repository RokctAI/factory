## Question (4 marks)

Given f(x) = x^3 - 8x^2 + 5x + 14 with x-intercepts A, B and C. The coordinates of B are (2 ; 0). Use the graph to determine the values of x for which f(x) . f''(x) < 0

## Method

sign analysis product

## Memo working

With B(2 ; 0) known, divide out the factor (x - 2): f(x) = (x - 2)(x^2 - 6x - 7) = (x - 2)(x - 7)(x + 1), so the x-intercepts are x = -1, x = 2 and x = 7. From Q9.2, f''(x) < 0 for x < 8/3 and f''(x) > 0 for x > 8/3. The product f(x) . f''(x) is negative where the two factors have opposite signs. Reading the graph: f is positive with f'' negative on -1 < x < 2, and f is negative with f'' positive on 8/3 < x < 7. So the product is negative for -1 < x < 2 or 8/3 < x < 7.

## Answer (per marking guidelines)

-1 < x < 2 or 8/3 < x < 7
