## Question (3 marks)

The volume of the cylinder in Q10.1 is given by V = 25x^2/(4π) - x^3/(4π). Calculate the value of x that will maximise the volume of the cylinder.

## Method

optimisation set derivative zero

## Memo working

At the maximum volume the derivative of V with respect to x is zero. Differentiate: V'(x) = 50x/(4π) - 3x^2/(4π). Set V'(x) = 0 and multiply through by 4π: 50x - 3x^2 = 0, so x(50 - 3x) = 0. Since x ≠ 0 for a real cylinder, 50 - 3x = 0, giving x = 50/3 = 16,67.

## Answer (per marking guidelines)

x = 50/3 = 16,67
