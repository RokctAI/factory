## Question (3 marks)

Calculate the value of x that will maximise the volume of the cylinder.

## Method

optimisation set derivative zero

## Memo working

V'(x) = 50x/(4π) - 3x^2/(4π) = 0; 50x - 3x^2 = 0; x(50 - 3x) = 0; x ≠ 0, so x = 50/3 = 16,67

## Answer (per marking guidelines)

x = 50/3 = 16,67
