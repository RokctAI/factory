## Question (6 marks)

If it is further given that the gradient of AD is -4 and the length of AD is sqrt(612) units, calculate the coordinates of A.

## Method

line and distance equations

## Memo working

Equation AD: -9 = -4(3) + c -> c = 3, y = -4x + 3; (x - 3)^2 + (y + 9)^2 = 612; substitute: (x - 3)^2 + (-4x + 12)^2 = 612; 17x^2 - 102x - 459 = 0; x^2 - 6x - 27 = 0; (x - 9)(x + 3) = 0; x = -3 (x = 9 not applicable, A in second quadrant); y = -4(-3) + 3 = 15; A(-3 ; 15)

(Memo note: Alternative memo method: y-intercept N(0 ; 3) of AD, ND = 3√17 = ½AD, so N is the midpoint of AD, giving A(-3 ; 15).)

## Answer (per marking guidelines)

A(-3 ; 15)
