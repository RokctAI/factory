## Question (6 marks)

Triangle ACD has vertices A, D(3 ; -9) and C(-9 ; 0), where A is a point in the second quadrant. B(-1 ; k) lies on side DC. (In the diagram, A lies above the x-axis in the second quadrant, C(-9 ; 0) is on the x-axis, D(3 ; -9) is below the x-axis, and B(-1 ; k) is marked on line DC between C and D.) If it is further given that the gradient of AD is -4 and the length of AD is sqrt(612) units, calculate the coordinates of A.

## Method

line and distance equations

## Memo working

Equation of AD through D(3 ; -9) with gradient -4: -9 = -4(3) + c gives c = 3, so y = -4x + 3. A lies on this line at distance sqrt(612) from D: (x - 3)^2 + (y + 9)^2 = 612. Substitute y + 9 = -4x + 12: (x - 3)^2 + (-4x + 12)^2 = 612, which expands to 17x^2 - 102x - 459 = 0, i.e. x^2 - 6x - 27 = 0, so (x - 9)(x + 3) = 0 and x = -3 (x = 9 is not applicable since A is in the second quadrant). Then y = -4(-3) + 3 = 15, so A(-3 ; 15). (Alternative memo method: the y-intercept N(0 ; 3) of AD satisfies ND = 3√17 = ½AD, so N is the midpoint of AD, giving A(-3 ; 15).)

## Answer (per marking guidelines)

A(-3 ; 15)
