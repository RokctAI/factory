## Question (2 marks)

Write down the values of x in the interval x ∈ [-180° ; 0°] for which f(x) <= 0.

## Method

read sign from graph

## Memo working

tan x <= 0 at x = -180° and on (-90° ; 0°]

## Answer (per marking guidelines)

x = -180° or x ∈ (-90° ; 0°]  (i.e. x = -180° or -90° < x <= 0°)
