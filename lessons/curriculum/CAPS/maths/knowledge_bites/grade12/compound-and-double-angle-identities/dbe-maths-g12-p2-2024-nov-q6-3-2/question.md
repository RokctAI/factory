## Question (1 mark)

Write down the smallest possible value of x for which g will have a maximum value in the interval x ∈ (0° ; 360°].

## Method

solve for max position

## Memo working

cos 2x = 1 at 2x = 360° -> x = 180° (0° excluded from the interval)

## Answer (per marking guidelines)

x = 180°
