## Question (7 marks)

It is given that sin^2 x ; cos^2 x and (1/2) sin 2x are the first three terms of an arithmetic sequence. The constant difference of the arithmetic sequence is NOT zero. Determine the general solution for x.

## Method

arithmetic condition trig equation

## Memo working

cos^2 x - sin^2 x = (1/2)sin 2x - cos^2 x; (1/2)(2 sin x cos x) = sin x cos x; 2cos^2 x - sin x cos x - sin^2 x = 0; (2cos x + sin x)(cos x - sin x) = 0; tan x = -2 or tan x = 1; ref angle 63,43° or 45°; x = 116,57° + k.180° or x = 45° + k.180°, k ∈ Z; since the constant difference is NOT zero, x = 116,57° + k.180°

(Memo note: The memo shows x ≠ 45° + k.180° (rejected because the difference would be zero); final answer x = 116,57° + k.180°, k ∈ Z. An alternative memo factorisation groups (cos x - sin x)(cos x + sin x) + cos x(cos x - sin x) = 0.)

## Answer (per marking guidelines)

x = 116,57° + k.180°, k ∈ Z (x = 45° + k.180° gives constant difference zero, excluded)
