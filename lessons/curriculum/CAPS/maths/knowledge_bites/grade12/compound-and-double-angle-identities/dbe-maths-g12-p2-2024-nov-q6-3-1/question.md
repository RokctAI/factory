## Question (3 marks)

Consider the function: g(x) = (4 - 8sin^2 x)/3. Calculate the maximum value of g.

## Method

double angle max value

## Memo working

g(x) = 4(1 - 2sin^2 x)/3 = 4cos 2x / 3; maximum of cos 2x is 1, so maximum of g is 4/3

(Memo note: Alternative memo method: 4 - 8sin^2 x is a maximum when sin^2 x is a minimum (0), giving 4/3.)

## Answer (per marking guidelines)

Maximum value of g(x) = 4/3
