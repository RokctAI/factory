## Question (6 marks)

Prove that: [tan(180° - x)](1 - cos^2 x) + cos^2 x = ((sin x - cos x)(1 + sin x.cos x))/(-cos x)

## Method

identity proof difference of cubes

## Memo working

Work from the left-hand side. Reduce tan(180° - x) to -tan x, and replace 1 - cos^2 x with sin^2 x (square identity): LHS = (-tan x)(sin^2 x) + cos^2 x. Write tan x as sin x/cos x: LHS = -(sin x/cos x)(sin^2 x) + cos^2 x = -sin^3 x/cos x + cos^2 x. Put both terms over the common denominator -cos x: multiplying cos^2 x by (-cos x)/(-cos x) gives -cos^3 x on top, so LHS = (sin^3 x - cos^3 x)/(-cos x). The numerator is a difference of cubes: sin^3 x - cos^3 x = (sin x - cos x)(sin^2 x + sin x.cos x + cos^2 x). Since sin^2 x + cos^2 x = 1, the second bracket is 1 + sin x.cos x. Therefore LHS = (sin x - cos x)(1 + sin x.cos x)/(-cos x) = RHS. (Alternative memo method: start from the right-hand side, expand (sin x - cos x)(cos^2 x + sin^2 x + sin x.cos x), simplify to (sin^3 x - cos^3 x)/(-cos x), split the fraction and use the quotient and square identities to reach the left-hand side.)

## Answer (per marking guidelines)

LHS = RHS (identity proved)
