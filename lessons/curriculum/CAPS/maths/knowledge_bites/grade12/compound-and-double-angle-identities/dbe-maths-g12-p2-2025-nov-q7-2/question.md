## Question (3 marks)

On the set of axes provided in the ANSWER BOOK, draw the graph of g(x) = tan 2x - 1 for x ∈ [-135° ; 135°].

## Method

sketch tan graph

## Memo working

The graph is a tan graph compressed to period 90° (because of the 2x) and shifted 1 unit down (because of the -1). Find the three features the memo awards marks for. Asymptotes: tan 2x is undefined where 2x = ±90° + k.180°, so the vertical asymptotes are at x = ±45° and x = ±135°. Intercepts: the y-intercept is g(0) = tan 0° - 1 = -1, the point (0 ; -1); the x-intercepts are where tan 2x = 1, that is 2x = 45° + k.180°, giving x = -67,5°, x = 22,5° and x = 112,5° in the interval. Shape: each branch rises from bottom-left to top-right between consecutive asymptotes, passing through its x-intercept. Memo awards: asymptotes; shape; intercepts with axes.

## Answer (per marking guidelines)

tan graph with period 90° shifted 1 unit down: vertical asymptotes at x = ±45° and x = ±135°; y-intercept (0 ; -1); x-intercepts at x = -67,5°, 22,5° and 112,5°
