## Question (2 marks)

Hence, determine the values of x in the interval x ∈ [0° ; 360°] for which sqrt( (sin(540° + x).cos(90° + x))/sin(-x) ) will be real. (From QUESTION 5.2.1: the expression inside the square root simplifies to -sin x.)

## Method

non negative condition

## Memo working

A square root is real only when the quantity under it is not negative. From QUESTION 5.2.1 the expression equals -sin x, so we need -sin x ≥ 0, that is sin x ≤ 0. On [0° ; 360°], sine is negative in the third and fourth quadrants. The endpoints where sin x = 0 (0°, 180°, 360°) must be excluded, because there the original denominator sin(-x) is zero and the expression is undefined. That leaves 180° < x < 360°.

## Answer (per marking guidelines)

x ∈ (180° ; 360°)  OR  180° < x < 360°
