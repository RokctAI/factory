## Question (2 marks)

Hence, determine the values of x in the interval x ∈ [0° ; 360°] for which sqrt( (sin(540° + x).cos(90° + x))/sin(-x) ) will be real.

## Method

non negative condition

## Memo working

Need -sin x ≥ 0, i.e. sin x ≤ 0 (excluding the zero denominator): 180° < x < 360°

## Answer (per marking guidelines)

x ∈ (180° ; 360°)  OR  180° < x < 360°
