## Question (4 marks)

Determine the values of x for which (1 - tan 2x)(cos 2x) ≥ 0 in the interval x ∈ [0° ; 135°].

## Method

sign analysis using graphs

## Memo working

tan 2x - 1 = 0 at x = 22,5°; rewrite: -(tan 2x - 1)(cos 2x) ≥ 0, i.e. (tan 2x - 1)(cos 2x) ≤ 0; reading from the graphs of g and f: x ∈ [0° ; 22,5°] ∪ [112,5° ; 135°)

## Answer (per marking guidelines)

x ∈ [0° ; 22,5°] ∪ [112,5° ; 135°)  OR  0° ≤ x ≤ 22,5° or 112,5° ≤ x < 135°
