## Question (4 marks)

Determine the values of x for which (1 - tan 2x)(cos 2x) ≥ 0 in the interval x ∈ [0° ; 135°]. (From QUESTION 7: f(x) = cos 2x and g(x) = tan 2x - 1 are drawn for x ∈ [-135° ; 135°].)

## Method

sign analysis using graphs

## Memo working

Rewrite the inequality in terms of the drawn graphs: 1 - tan 2x = -(tan 2x - 1) = -g(x), so (1 - tan 2x)(cos 2x) ≥ 0 is the same as (tan 2x - 1)(cos 2x) ≤ 0 — we need g and f to have opposite signs (or a zero). The key x-values in [0° ; 135°] are x = 22,5° where tan 2x - 1 = 0, x = 45° where both graphs break (cos 2x = 0 and tan 2x undefined), and x = 112,5° where tan 2x - 1 = 0 again. Reading the signs from the graphs: from 0° to 22,5°, g is negative while f is positive, so the product g·f is negative — included. From 22,5° up to the asymptote region and on through to 112,5°, g and f carry the same sign, so the product is positive — excluded. From 112,5° towards 135°, g is zero and then positive while f is negative, giving g·f ≤ 0 as required — included up to, but excluding, x = 135°, where tan 2x is undefined.

## Answer (per marking guidelines)

x ∈ [0° ; 22,5°] ∪ [112,5° ; 135°)  OR  0° ≤ x ≤ 22,5° or 112,5° ≤ x < 135°
