## Question (6 marks)

Given: f(x) = sqrt(6sin^2 x - 11cos(90° + x) + 7). Solve for x in the interval x ∈ (0° ; 360°) if f(x) = 2.

## Method

trig quadratic equation

## Memo working

Square both sides: 6sin^2 x - 11cos(90° + x) + 7 = 4; cos(90° + x) = -sin x; 6sin^2 x + 11sin x + 3 = 0; (3sin x + 1)(2sin x + 3) = 0; sin x = -1/3 (sin x = -3/2 no solution); ref angle = 19,47°; x = 199,47° or x = 340,53°

## Answer (per marking guidelines)

x = 199,47° or x = 340,53°
