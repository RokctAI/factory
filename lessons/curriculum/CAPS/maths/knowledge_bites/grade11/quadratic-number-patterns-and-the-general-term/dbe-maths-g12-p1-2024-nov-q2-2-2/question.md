## Question (5 marks)

If it is further given that the third term of the quadratic pattern is 32, determine the general term, Tn, of the quadratic pattern.

## Method

quadratic pattern general term

## Memo working

Pattern 28 ; 29 ; 32 with first differences 1 ; 3 ; 5 ; 7 and second difference 2. 2a = 2 -> a = 1; 3a + b = 1 -> b = -2; T3 = 9a + 3b + c = 32 -> c = 29 (or 1 - 2 + c = 28 -> c = 29). Tn = n^2 - 2n + 29

## Answer (per marking guidelines)

Tn = n^2 - 2n + 29
