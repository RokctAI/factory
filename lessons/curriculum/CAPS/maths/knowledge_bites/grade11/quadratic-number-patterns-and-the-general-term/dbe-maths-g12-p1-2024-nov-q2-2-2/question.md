## Question (5 marks)

If it is further given that the third term of the quadratic pattern (with first differences 1 ; 3 ; 5 ; ...) is 32, determine the general term, Tn, of the quadratic pattern.

## Method

quadratic pattern general term

## Memo working

The pattern is 28 ; 29 ; 32 ; ... with first differences 1 ; 3 ; 5 ; 7 and constant second difference 2. For Tn = an^2 + bn + c: 2a = 2 -> a = 1; 3a + b = 1 -> b = -2; use T3 = 32: 9a + 3b + c = 32 -> 9 - 6 + c = 32 -> c = 29 (or from T1: 1 - 2 + c = 28 -> c = 29). So Tn = n^2 - 2n + 29

## Answer (per marking guidelines)

Tn = n^2 - 2n + 29
