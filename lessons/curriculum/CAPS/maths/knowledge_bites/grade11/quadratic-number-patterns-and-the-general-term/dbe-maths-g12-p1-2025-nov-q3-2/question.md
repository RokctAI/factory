## Question (3 marks)

Show that the depth of the torpedo at the end of n seconds was Tn = -n^2 + 38n - 1  (Quadratic pattern of depths: 36 ; 71 ; 104 ; ... at the end of 1, 2, 3, ... seconds)

## Method

quadratic pattern general term

## Memo working

For a quadratic pattern Tn = an^2 + bn + c, the second difference equals 2a. Here the second difference is -2, so 2a = -2 -> a = -1. The first first-difference equals 3a + b: 3(-1) + b = 35 -> b = 38. The first term equals a + b + c: -1 + 38 + c = 36 -> c = -1. Therefore Tn = -n^2 + 38n - 1. (Check: T2 = -4 + 76 - 1 = 71 and T3 = -9 + 114 - 1 = 104.)

## Answer (per marking guidelines)

Tn = -n^2 + 38n - 1
