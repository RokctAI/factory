## Question (3 marks)

Calculate the maximum depth that the torpedo reached. (Depth after n seconds: Tn = -n^2 + 38n - 1)

## Method

quadratic turning point

## Memo working

The general term Tn = -n^2 + 38n - 1 is a concave-down quadratic, so the maximum is at the turning point n = -b/(2a) = -38/(2(-1)) = 19. Substitute back: T19 = -(19)^2 + 38(19) - 1 = -361 + 722 - 1 = 360. (Memo alternative: set the derivative T'n = -2n + 38 = 0 -> n = 19.)

## Answer (per marking guidelines)

360 (metres, at n = 19)
