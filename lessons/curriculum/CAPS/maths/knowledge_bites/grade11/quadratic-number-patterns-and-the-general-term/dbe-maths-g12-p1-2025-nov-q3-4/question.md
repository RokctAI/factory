## Question (2 marks)

After how many seconds was the torpedo at 104 m below sea level for the second time? (Depth after n seconds: Tn = -n^2 + 38n - 1, maximum at n = 19)

## Method

quadratic pattern symmetry

## Memo working

The depth was 104 m at n = 3 (from the table). A quadratic pattern is symmetric about its turning point at n = 19, so the second time at the same depth satisfies (n + 3)/2 = 19, giving n + 3 = 38, so n = 35. (Memo alternative: solve -n^2 + 38n - 1 = 104 directly: n^2 - 38n + 105 = 0; (n - 35)(n - 3) = 0; n = 35.)

## Answer (per marking guidelines)

n = 35 (seconds)
