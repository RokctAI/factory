## Question (5 marks)

The graphs of g(x) = x + c and f(x) = a/(x + p) + q are drawn, and graph g and the vertical asymptote of f intersect at the x-axis. Graph g intersects the horizontal asymptote of graph f at x = 1 and the graph f at x = 3. Graphs f and g also intersect on the y-axis. Determine the equation of f.

## Method

solve hyperbola parameters from conditions

## Memo working

The x-intercept of g is x = -c, and this is where the vertical asymptote of f meets the x-axis, so -p = -c, meaning p = c. Graph g meets the horizontal asymptote y = q at x = 1, so q = g(1) = 1 + c. This gives f(x) = a/(x + c) + 1 + c. The graphs meet on the y-axis at (0 ; c), so c = a/c + 1 + c, which gives a = -c. The point where g cuts f at x = 3 is (3 ; 3 + c), so 3 + c = -c/(3 + c) + 1 + c. Multiplying out: 9 + 6c + c^2 = -c + 3 + 4c + c^2, so 3c = -6 and c = -2. Then a = 2, p = -2 and q = -1, so f(x) = 2/(x - 2) - 1. (Alternative memo method: find a = 6 + 2c from the point (3 ; 3 + c) first, then use the y-axis intersection (0 ; c) to get c = -2, a = 2, q = -1.)

## Answer (per marking guidelines)

f(x) = 2/(x - 2) - 1
