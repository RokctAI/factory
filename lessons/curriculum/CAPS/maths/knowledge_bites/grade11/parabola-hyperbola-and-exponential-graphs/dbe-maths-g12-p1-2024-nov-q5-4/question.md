## Question (3 marks)

For which values of x is f(x) >= 0, where f(x) = -3/(x - 1) - 2?

## Method

hyperbola inequality

## Memo working

Find the x-intercept: -3/(x - 1) - 2 = 0 -> -3 = 2x - 2 -> x = -1/2. On the branch between this intercept and the vertical asymptote x = 1 the graph rises above the x-axis, so f(x) >= 0 from the x-intercept up to (but excluding) the asymptote.

## Answer (per marking guidelines)

x ∈ [-1/2 ; 1)  OR  -1/2 <= x < 1
