## Question (1 mark)

Sketched below is the graph of f(x) = a/(x + p) + q having the domain (-∞ ; 1) ∪ (1 ; ∞). The graph of f cuts the y-axis at (0 ; 1). A line of symmetry of f is given by g(x) = x - 3. (Figure: hyperbola with vertical asymptote x = 1, dotted, and a horizontal asymptote below the x-axis, dotted; the left branch passes through (0 ; 1); the increasing line g crosses both asymptotes.) Write down the value of p.

## Method

read asymptote from domain

## Memo working

The domain excludes only x = 1, so the vertical asymptote is x = 1, which means p = -1

## Answer (per marking guidelines)

p = -1
