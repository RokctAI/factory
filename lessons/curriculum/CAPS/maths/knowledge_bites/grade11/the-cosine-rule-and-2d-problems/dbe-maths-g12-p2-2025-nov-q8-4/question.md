## Question (4 marks)

If AB = BK, calculate the size of KÂC. (From QUESTIONS 8.1 to 8.3: the vertical rectangle ABCD has AB = 18 cm and diagonal AC = 18√5 cm; the base diagonal KC = 43,97 cm; the backdrop is vertical to the base, so AB ⊥ BK.)

## Method

cosine rule in 3d

## Memo working

First find AK. The backdrop stands vertical on the horizontal base, so AB is perpendicular to BK and triangle ABK is right-angled at B. With AB = BK = 18: AK^2 = AB^2 + BK^2 = 18^2 + 18^2 (Pythagoras), so AK = √648 = 18√2 = 25,46 cm. Now triangle AKC has all three sides known: AK = 18√2, AC = 18√5 and KC = 43,97. Apply the cosine rule with the angle at A: KC^2 = AK^2 + AC^2 - 2.AK.AC cos KÂC, so (43,97)^2 = (18√2)^2 + (18√5)^2 - 2(18√2)(18√5)cos KÂC. Solving: cos KÂC = 0,16..., so KÂC = 80,60°.

## Answer (per marking guidelines)

KÂC = 80,60°
