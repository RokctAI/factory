## Question (2 marks)

Determine the equation of QR. (From QUESTION 3: Q(-4 ; -6) and R(12 ; 2); from QUESTION 3.2 the gradient of QR is 1/2.)

## Method

line equation point gradient

## Memo working

Use y = mx + c with m = 1/2 and the point Q(-4 ; -6): -6 = (1/2)(-4) + c -> -6 = -2 + c -> c = -4 (or use point R: y - 2 = (1/2)(x - 12)). So y = (1/2)x - 4.

## Answer (per marking guidelines)

y = (1/2)x - 4
