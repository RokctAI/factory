## Question (5 marks)

Solve for x:  sqrt( sqrt(1/x) + 2 ) = 1/sqrt(x)

## Method

surd equation squaring twice

## Memo working

Square both sides: sqrt(1/x) + 2 = 1/x. Isolate the remaining surd: sqrt(1/x) = 1/x - 2, and square again: 1/x = 1/x^2 - 4/x + 4. Bring everything to one side: 1/x^2 - 5/x + 4 = 0, and multiply through by x^2: 4x^2 - 5x + 1 = 0. Factorise: (4x - 1)(x - 1) = 0, so x = 1/4 or x = 1. Check both in the original equation: x = 1/4 gives sqrt(sqrt(4) + 2) = sqrt(4) = 2 and 1/sqrt(1/4) = 2, which is valid; x = 1 gives sqrt(3) on the left but 1 on the right, so x = 1 is rejected. (Memo alternative: substitute k = sqrt(1/x), so sqrt(k + 2) = k; k^2 - k - 2 = 0; (k - 2)(k + 1) = 0; k = 2 with k = -1 rejected; then sqrt(1/x) = 2 -> x = 1/4.)

## Answer (per marking guidelines)

x = 1/4 (x = 1 rejected)
