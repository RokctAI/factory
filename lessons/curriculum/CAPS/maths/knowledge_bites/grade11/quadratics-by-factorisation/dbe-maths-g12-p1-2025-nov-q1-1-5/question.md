## Question (5 marks)

Solve for x:  sqrt( sqrt(1/x) + 2 ) = 1/sqrt(x)

## Method

surd equation squaring twice

## Memo working

Square both sides: sqrt(1/x) + 2 = 1/x; isolate surd: sqrt(1/x) = 1/x - 2; square again: 1/x = 1/x^2 - 4/x + 4; 1/x^2 - 5/x + 4 = 0; 4x^2 - 5x + 1 = 0; (4x - 1)(x - 1) = 0; x = 1/4, and x = 1 is rejected on checking

(Memo note: Alternative memo method substitutes k = sqrt(1/x): sqrt(k + 2) = k; k^2 - k - 2 = 0; (k - 2)(k + 1) = 0; k = 2 (k = -1 rejected); sqrt(1/x) = 2 -> x = 1/4.)

## Answer (per marking guidelines)

x = 1/4 (x = 1 rejected)
