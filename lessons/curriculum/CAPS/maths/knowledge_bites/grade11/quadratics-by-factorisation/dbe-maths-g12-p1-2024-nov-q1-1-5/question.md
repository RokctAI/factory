## Question (4 marks)

Solve for x:  sqrt(-2x + 4) - x = 2

## Method

surd equation squaring

## Memo working

Isolate the surd: sqrt(-2x + 4) = 2 + x. Square both sides: -2x + 4 = 4 + 4x + x^2. Rearrange: x^2 + 6x = 0, and factorise: x(x + 6) = 0 -> x = 0 or x = -6. Check both in the original equation: x = 0 gives sqrt(4) - 0 = 2 (valid); x = -6 gives sqrt(16) + 6 = 10 ≠ 2, so x = -6 is rejected.

## Answer (per marking guidelines)

x = 0 (x = -6 rejected)
