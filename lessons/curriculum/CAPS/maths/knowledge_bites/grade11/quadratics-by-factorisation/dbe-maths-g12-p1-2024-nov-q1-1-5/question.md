## Question (4 marks)

Solve for x:  sqrt(-2x + 4) - x = 2

## Method

surd equation squaring

## Memo working

sqrt(-2x+4) = 2 + x; square both sides: -2x + 4 = 4 + 4x + x^2; x^2 + 6x = 0; x(x+6) = 0; x = 0 or x = -6 (rejected on checking)

## Answer (per marking guidelines)

x = 0 (x = -6 rejected)
