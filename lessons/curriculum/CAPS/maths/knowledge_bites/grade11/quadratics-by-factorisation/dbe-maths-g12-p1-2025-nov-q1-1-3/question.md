## Question (4 marks)

Solve for x:  8x^2 > 2x

## Method

quadratic inequality

## Memo working

Standard form 8x^2 - 2x > 0; 2x(4x - 1) > 0; critical values x = 0 and x = 1/4; sign analysis -> x < 0 or x > 1/4

## Answer (per marking guidelines)

x < 0 or x > 1/4
