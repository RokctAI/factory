## Question (2 marks)

Solve for x:  x(x - 3) = 0

## Method

zero product property

## Memo working

The product of two factors is zero, so at least one factor must be zero: x(x-3) = 0 -> x = 0 or x - 3 = 0 -> x = 0 or x = 3

## Answer (per marking guidelines)

x = 0 or x = 3
