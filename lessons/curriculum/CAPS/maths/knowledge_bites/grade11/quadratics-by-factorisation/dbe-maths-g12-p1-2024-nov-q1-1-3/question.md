## Question (4 marks)

Solve for x:  x^2 - 2x - 3 > 0

## Method

quadratic inequality

## Memo working

Factorise the quadratic: (x - 3)(x + 1) > 0. Critical values are x = 3 and x = -1. Sign analysis: the parabola opens upwards, so the expression is positive outside the roots -> x < -1 or x > 3. (Memo note: answer only earns 3/4.)

## Answer (per marking guidelines)

x < -1 or x > 3  OR  x ∈ (-∞ ; -1) ∪ (3 ; ∞)
