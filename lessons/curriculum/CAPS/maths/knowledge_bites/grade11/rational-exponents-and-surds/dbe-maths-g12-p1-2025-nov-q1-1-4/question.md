## Question (4 marks)

Solve for x:  2.2^(2x) - 9.2^x + 4 = 0

## Method

exponential equation factorise

## Memo working

This is a quadratic in 2^x. Factorise directly: (2.2^x - 1)(2^x - 4) = 0, so 2^x = 1/2 or 2^x = 4. Write each side with base 2: 2^x = 2^(-1) or 2^x = 2^2. Equate exponents: x = -1 or x = 2. (Memo alternative: substitute k = 2^x to get 2k^2 - 9k + 4 = 0; (2k - 1)(k - 4) = 0; k = 1/2 or k = 4, then solve 2^x = k as above.)

## Answer (per marking guidelines)

x = -1 or x = 2
