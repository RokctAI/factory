## Question (5 marks)

Solve for x:  2^(2x) - 2^(x+2) - 32 = 0

## Method

exponential equation substitution

## Memo working

Rewrite using exponent laws: 2^(2x) - 2^2·2^x - 32 = 0, a quadratic in 2^x. Factorise: (2^x - 8)(2^x + 4) = 0, so 2^x = 8 or 2^x = -4. An exponential is never negative, so 2^x = -4 has no solution. From 2^x = 8: 2^x = 2^3 -> x = 3

## Answer (per marking guidelines)

x = 3
