## Question (3 marks)

Draw a histogram to represent the information provided in the cumulative frequency table. (Cumulative frequency table from QUESTION 2.1: 0 < t ≤ 20 -> 16; 0 < t ≤ 40 -> 40; 0 < t ≤ 60 -> 59; 0 < t ≤ 80 -> 67; 0 < t ≤ 100 -> 70.)

## Method

histogram from cumulative frequencies

## Memo working

First convert cumulative frequencies to class frequencies by subtracting each cumulative total from the next: 16; 40 - 16 = 24; 59 - 40 = 19; 67 - 59 = 8; 70 - 67 = 3. Then draw one bar per interval — (0;20], (20;40], (40;60], (60;80], (80;100] — with heights 16, 24, 19, 8 and 3, and with no gaps between the bars. Memo awards: two frequencies correct; all frequencies correct; no gaps between bars.

## Answer (per marking guidelines)

Histogram with class frequencies 16 ; 24 ; 19 ; 8 ; 3 for the intervals (0;20], (20;40], (40;60], (60;80], (80;100]
