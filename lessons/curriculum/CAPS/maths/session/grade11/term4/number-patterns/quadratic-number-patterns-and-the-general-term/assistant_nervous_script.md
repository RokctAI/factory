Hey, it's Bianca — if quadratic patterns feel like linear patterns that suddenly grew teeth, take a breath, because the whole topic runs on one table and three small facts, and you already own every skill it borrows.

The table first. Write the terms, write the gaps, write the gaps of the gaps. If the first gaps repeat, it is grade ten's linear pattern — done. If the SECOND gaps repeat, it is quadratic, and that steady number at the bottom is your first prize: halve it, and you have a.

Then the two other facts, in order. The very first gap equals 3a plus b — you know a, so b falls out. The very first term equals a plus b plus c — you know both, so c falls out. a, then b, then c, each one feeding the next. Assemble Tn, then spend ten seconds testing it on a term you did not use. That tiny test is the difference between confidence and hope.

Using the formula is driving a machine with two gears. Forward gear: feed in a position, out comes the term — the fiftieth term without listing forty-nine others. Reverse gear: given a value, set the formula equal to it and solve the quadratic — your factorising from last year, back on duty. Just remember positions are seats: whole and positive. Reject the negative root out loud, and if the discriminant refuses to be a perfect square, say the honest sentence: that number is never a term.

Picture patterns are the same machine wearing overalls: count the first figures, difference, build, and answer in tiles and figures, not bare numbers.

Gaps, gaps of gaps, halve the bottom, three screws in order, test on an unseen term. That is the entire topic — one table and a quadratic equation you have solved a hundred times. You've got this!
