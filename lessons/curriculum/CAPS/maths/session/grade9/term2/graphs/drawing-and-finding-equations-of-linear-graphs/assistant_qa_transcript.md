### subtopic_1 — Drawing a Line From a Table of Values
**Assistant:** Why is a third point plotted when two points already fix a straight line?

**Tutor:** Because two points fix a line whether or not they are correct, so two points can never reveal an arithmetic slip, while three points can. If one of the three has been miscalculated, it sits off the line through the other two and the error is visible before the ruler touches the page; if all three line up, each one has been checked by the other two. For y equals 2x minus 1 with x equals negative 1, 0 and 1, the substitutions give negative 3, negative 1 and 1, and the points negative 1 semicolon negative 3, 0 semicolon negative 1 and 1 semicolon 1 line up with a constant difference of 2, which is the gradient. Choosing x values close to zero keeps the arithmetic small and the points on a small grid, and when the coefficient is a fraction, choose x values that clear it: for y equals one half x plus 3, the values negative 2, 0 and 2 give the whole numbers 2, 3 and 4. The line is then ruled through the points, extended past them with arrowheads at both ends because the equation holds for every x, and labelled with its equation, which matters whenever more than one line shares the axes. The table method is slower than the methods that follow but it always works, and its built-in check is why it is the method to fall back on whenever a faster method feels unsafe.

### subtopic_2 — Drawing Using Intercepts and the Gradient
**Assistant:** How does the gradient-intercept method turn the equation into a picture without a table?

**Tutor:** It reads the two numbers in y equals mx plus c as drawing instructions. The constant c is the y-intercept, so the first point is 0 semicolon c on the vertical axis. The gradient m is rise over run, so from that point you move 1 unit to the right and m units up, or m units down if m is negative, and repeat to obtain further points. For y equals 2x minus 1, start at 0 semicolon negative 1, step to 1 semicolon 1 and then to 2 semicolon 3. For y equals negative 2x plus 4, start at 0 semicolon 4 and step down to 1 semicolon 2 and 2 semicolon 0, producing a line that falls from left to right, as a negative gradient must. A fractional gradient such as one half is read as 1 up for 2 across. The dual-intercept method is a cousin: substitute x equals 0 for the y-intercept and y equals 0 for the x-intercept, plot both points and rule through them; for y equals negative 2x plus 4 those are 0 semicolon 4 and 2 semicolon 0. It fails only for a line through the origin, where both intercepts coincide, and then a second point such as 1 semicolon 3 for y equals 3x is plotted instead. Two lines need separate treatment: y equals 3 is horizontal through 0 semicolon 3 with gradient zero, and x equals negative 2 is vertical through negative 2 semicolon 0 and is not of the form y equals mx plus c at all.

### subtopic_3 — Finding the Equation From a Drawn Line
**Assistant:** In what order should I read a drawn line to get its equation reliably?

**Tutor:** Read c first, calculate m second, write the equation third, and verify with a point fourth. The y-intercept c is read where the line crosses the vertical axis, which for the line through 0 semicolon negative 3 and 3 semicolon 3 is negative 3. The gradient m is rise over run between two points where the line passes exactly through grid intersections: from 0 semicolon negative 3 to 3 semicolon 3 the rise is 3 minus negative 3, which is 6, and the run is 3 minus 0, which is 3, so m is 2. The equation is y equals 2x minus 3. The verification uses a third point on the line, such as 1 semicolon negative 1: 2 times 1 minus 3 is negative 1, so the equation matches the picture. The sign of m must agree with the direction of the line, rising for positive and falling for negative; a line from 0 semicolon 5 down to 5 semicolon 0 has m equal to negative 1 and equation y equals negative x plus 5. Parallel lines share a gradient, so the line through negative 2 semicolon 0 and 0 semicolon 4, with m equal to 2 and c equal to 4, is parallel to the first. Horizontal and vertical lines are written directly: y equals 3 for a horizontal line through 0 semicolon 3 and x equals negative 2 for a vertical line through negative 2 semicolon 0. The verification is the step markers look for, because reading a picture can be off by a block.

### subtopic_4 — Lines Through Two Points and the Error Museum
**Assistant:** How do I find c when the line's y-intercept is not shown on the graph?

**Tutor:** Calculate the gradient from two known points first, then substitute either point into y equals mx plus c and solve for c, because every point on the line satisfies its equation. For a line through 1 semicolon 5 and 3 semicolon 9, the rise is 9 minus 5, which is 4, and the run is 3 minus 1, which is 2, so m is 2. Substituting 1 semicolon 5 into y equals 2x plus c gives 5 equals 2 plus c, so c is 3 and the equation is y equals 2x plus 3. The other point is the check: 2 times 3 plus 3 is 9. For a falling line through 2 semicolon 1 and 4 semicolon negative 3, the rise is negative 3 minus 1, which is negative 4, over a run of 2, so m is negative 2; substituting 2 semicolon 1 gives 1 equals negative 4 plus c, so c is 5, and the equation is y equals negative 2x plus 5. This two-point method also protects against the third exhibit in the error museum, reading c from a graph whose vertical axis is not drawn at x equals 0; when in doubt, use a point rather than the axis. The other exhibits are a table with only two points hiding an arithmetic error, a staircase stepped upward for a negative gradient, run over rise, y equals 3 drawn through the origin with gradient 3, and unlabelled lines on shared axes. A verification point catches each one, which is why the layout for finding an equation always ends with a third point substituted into the finished formula.
