Hey — if solving by factorising felt like a lot of new steps, here is the calm version: it is one fact about zero, plus the factorising you already know.

The fact: if two things multiply to make zero, one of them is zero. Nothing else can do that. So when an equation looks like the bracket x minus 2 times the bracket x plus 7 equals 0, one bracket must be zero: x is 2, or x is negative 7. Two answers, joined by or.

If the equation is not in that shape yet, build it. First, get zero on one side by moving everything across. x squared equals 5x becomes x squared minus 5x equals 0. Never divide by x; that deletes the answer x equals 0. Second, factorise: x times the bracket x minus 5 equals 0. Third, each bracket to zero: x is 0 or x is 5.

For trinomials, play the two-number game: x squared plus 8x plus 15 equals 0 becomes the bracket x plus 3 times the bracket x plus 5 equals 0, so x is negative 3 or negative 5. Notice the signs flip; solve the little equations, do not read the brackets.

Then check both answers in the original. If there is a story, ask whether each answer makes sense, and write down why a negative width is rejected.

Zero on one side, factorise, each bracket to zero, check both. You've got this!
