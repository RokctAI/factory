### subtopic_1 — Substituting Into an Equation in Two Variables
**Assistant:** Why does the order inside an ordered pair matter so much?

**Tutor:** Because the pair is a compressed sentence that says which value belongs to which variable, and swapping the entries changes the meaning entirely. The convention is x first and y second, written with a semicolon in South African notation, so 2 semicolon 5 says that when x is 2, y is 5. For y equals 2x plus 1 that is true: 2 times 2 plus 1 is 5. The pair 5 semicolon 2 says that when x is 5, y is 2, and that is false for this equation, because 2 times 5 plus 1 is 11. Next week each pair becomes a point on the Cartesian plane, with the first entry measured along the horizontal axis and the second up the vertical axis, so a swapped pair is plotted in the wrong place and the graph is wrong even if every calculation was right. The habit to build now is to write the table with x on the top row and y underneath, read each column from top to bottom into the pair, and check one pair by substitution before moving on. The same convention explains why a table is called a table of ordered pairs rather than a table of values: the order is part of the information. An equation in two variables has infinitely many solutions, and the five pairs in the table are five of them, chosen on the standard run from negative 2 to 2.

### subtopic_2 — Tables for Linear and Non-Linear Rules
**Assistant:** How do the differences in a table tell me whether the rule is linear?

**Tutor:** A linear rule adds the same amount to y every time x increases by the same step, because y equals mx plus c changes by m for each unit increase in x. In the table for y equals 3x minus 2 over the run negative 2 to 2, the y values are negative 8, negative 5, negative 2, 1 and 4, and the differences are 3, 3, 3 and 3, which equal the coefficient of x. That constant difference is the evidence of linearity and will be called the gradient next week. A non-linear rule produces changing differences. For y equals x squared minus 1 the y values are 3, 0, negative 1, 0 and 3, and the differences are negative 3, negative 1, 1 and 3; they are not constant, so the rule is not linear, and their symmetry around the middle column reflects the fact that squaring a negative gives the same result as squaring the matching positive. For y equals 24 over x the values 24, 12, 8, 6 and 4 fall by shrinking amounts and the product of each pair is 24, which is an inverse relationship. Two cautions apply: the step in x must be constant for the differences to be compared, and at least three columns are needed, because any two points have a single difference and so always look linear. An examiner asking whether a relationship is linear expects the differences to be written beneath the table as the justification.

### subtopic_3 — Finding x When y Is Given
**Assistant:** When y is given, why do I get an equation to solve rather than a calculation?

**Tutor:** Because substituting a value for y leaves the unknown x inside the rule, with operations still wrapped around it, and unwrapping those operations is exactly what solving an equation means. For y equals 3x minus 2 with y equals 10, substitution gives 10 equals 3x minus 2. The right side has x multiplied by 3 and then reduced by 2, so the inverses from last lesson are applied in reverse order on both sides: add 2 to get 12 equals 3x, divide by 3 to get x equals 4. The completed pair is 4 semicolon 10, and the forwards check confirms it: 3 times 4 minus 2 is 10. Substituting a value for x, by contrast, leaves only numbers to evaluate, so forwards is arithmetic and backwards is an equation. The most frequent error is putting the given value into the wrong variable; replacing x with 10 gives 28, which answers a different question. Reading the question for which variable is given settles the direction. Squared rules produce two answers backwards: y equals x squared minus 1 with y equals 8 gives x squared equals 9, so x is 3 or negative 3, and both pairs belong in the table. Non-integer answers are legitimate too: y equals 2x plus 1 with y equals 6 gives x equals 2,5, and rounding it to 3 fails the check.

### subtopic_4 — From Table to Rule and the Error Museum
**Assistant:** How do I find the constant term of a linear rule when x equals 0 is not in the table?

**Tutor:** Find the coefficient from the differences first, then substitute any one pair from the table into y equals mx plus c and solve for c. With inputs 2, 3 and 4 and outputs 7, 10 and 13, the differences are 3 and 3 for steps of 1 in x, so the coefficient m is 3 and the rule has the form y equals 3x plus c. Take the pair 2 semicolon 7: 7 equals 3 times 2 plus c, so 7 equals 6 plus c and c is 1. The rule is y equals 3x plus 1, and the check with a pair not used to build it, x equals 4, gives 12 plus 1, which is 13. When x equals 0 is in the table the constant is read directly, because 3 times 0 is 0 and y at x equals 0 is c itself; that is why the standard run from negative 2 to 2 is convenient. The error museum for this lesson is short but costly: substituting a negative without brackets, which turns 2 times negative 2 plus 1 into 2 minus 2 plus 1; writing pairs y first; feeding a given y value into x; declaring a rule linear from two columns, when a third column is the test; and dropping the negative root when a squared rule is run backwards. Every one is caught by substituting the finished pair into the original equation and reading the question for which variable was given, and a marker gives method marks for the differences written beneath the table and for each line of the backwards equation.
