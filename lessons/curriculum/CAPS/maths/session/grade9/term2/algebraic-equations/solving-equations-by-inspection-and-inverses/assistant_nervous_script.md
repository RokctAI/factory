Hey — if equations felt like a long list of rules today, here is the calm version: an equation is a locked box with x inside, and there are only three ways to open it.

One: see it. x plus 7 is 12, so x is 5. For squares, remember there are two answers: x squared is 49 means x is 7 or negative 7.

Two: undo buttons, in reverse order, on both sides. 3x minus 5 equals 16: undo the minus 5 first by adding 5, then undo the times 3 by dividing by 3. x is 7. Shoes before socks. If there are brackets, open them first. If there are fractions, multiply everything by the number both bottoms fit into. If you end up dividing by a negative, divide by the negative.

Three: for powers, write both sides with the same base and match the little numbers. 3 to the power of x plus 1 equals 81, and 81 is 3 to the fourth, so x plus 1 is 4.

For word problems: pick a letter, say what it stands for, write the story as a sentence with an equals sign, undo, then answer the question that was actually asked.

And always put your answer back in the box to check. See it, undo it, same base, check it. You've got this!
