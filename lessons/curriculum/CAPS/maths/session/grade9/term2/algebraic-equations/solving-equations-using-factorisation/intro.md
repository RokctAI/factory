Today factorising solves the equations that inverses cannot. x squared plus 8x plus 15 equals 0 has x in two places with different powers, so no chain of undo buttons isolates it; instead we use the one thing only zero can do: if two quantities multiply to give zero, one of them must be zero. Factorise into the bracket x plus 3 times the bracket x plus 5 equals 0, set each factor to zero, and the solutions are x equals negative 3 or x equals negative 5. We get zero on one side before factorising, so x squared equals 5x keeps its solution x equals 0, and in context problems we reject an answer such as a negative width for a written reason. This is the Grade 9 doorway to quadratic equations.
