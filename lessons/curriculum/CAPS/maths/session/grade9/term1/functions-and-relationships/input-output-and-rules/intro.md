Today we study relationships between an input and an output — the number that goes in, the rule that acts on it, and the number that comes out — presented as flow diagrams, tables, formulae and equations. The anchor rule is "multiply by 3, then add 2": input 4 gives output 14, input negative 2 gives output negative 4, and the formula is y equals 3x plus 2. We will run rules forwards to find outputs, run them backwards to find inputs, read a rule off a table, and solve an equation as a flow diagram in reverse. The order of operations and the order of undoing them are the two ideas that carry every example. This is where last week's patterns become next year's functions, and the vocabulary of input, output and rule is the vocabulary Grade 10 will use from day one.
