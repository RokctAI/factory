# Part 1 — Expert

This session determines input values, output values and rules from flow diagrams, tables, formulae and equations. The anchor rule is "multiply by 3, then add 2", written y equals 3x plus 2: the input 4 produces the output 14; the output 32 is produced by the input 10. Finding an output is substitution; finding an input is solving an equation; finding a rule is reading the differences in a table. Each of the three is examinable, and the order of operations governs all of them.

## Subtopic: Flow Diagrams: Input, Rule, Output

A flow diagram shows an input entering on the left, one or more operations in boxes, and the output leaving on the right. The anchor: x enters, passes through "times 3", then through "plus 2", and y leaves. Input 4: 4 times 3 is 12, plus 2 is 14. Input 0: 0 plus 2 is 2. Input negative 2: negative 6 plus 2 is negative 4. Input one half: three halves plus 2 is three and a half.

The order of the boxes is the order of the operations, and it matters. Swap them — "plus 2" then "times 3" — and input 4 gives 6 times 3, which is 18, not 14. The first diagram is y equals 3x plus 2; the second is y equals 3 times the quantity x plus 2, which is 3x plus 6. Different rules, different outputs, and the bracket in the formula records which operation happened first.

Each box is one operation, and the usual operations are add, subtract, multiply, divide, square and square root. "Subtract 1, then multiply by 4": input 6 gives 5 times 4, which is 20. "Square, then subtract 3": input 5 gives 25 minus 3, which is 22; input 0 gives negative 3; input negative 5 also gives 22, because squaring loses the sign.

Running the diagram backwards finds the input from the output. Reverse the order of the boxes and replace each operation by its inverse. For "times 3, then plus 2" with output 20: undo the plus 2 first, 20 minus 2 is 18; then undo the times 3, 18 divided by 3 is 6. The input was 6. Check forwards: 6 times 3 is 18, plus 2 is 20. Correct. The inverse operations are the additive and multiplicative inverses you revised in the integers work: subtracting undoes adding, dividing undoes multiplying.

The order of undoing is the reverse of the order of doing, like taking off shoes before socks. Undo the last box first. Students who undo in the forward order — 20 divided by 3, then minus 2 — get a wrong and usually ugly input; the ugliness is itself a warning.

A flow diagram with a missing box is a rule-finding question. Input 4 produces 14, input 1 produces 5, and the first box is "times 3": 4 times 3 is 12, and 14 is 2 more; 1 times 3 is 3, and 5 is 2 more. The missing box is "plus 2". Two inputs are needed to confirm it.

The questions for this section are with you now: running a diagram forwards, running it backwards in reverse order, and filling a missing box.

## Subtopic: Tables and Finding the Rule

A table lists several inputs with their outputs. For inputs 1, 2, 3, 4 and outputs 5, 8, 11, 14, the rule is found exactly as last week's patterns were: the outputs rise by 3 for every rise of 1 in the input, so the rule multiplies by 3, and 1 times 3 is 3, so 2 is added. The rule is y equals 3x plus 2. Test on the last row: 3 times 4 plus 2 is 14. Correct.

Inputs are not always consecutive, and then the differences must be scaled. Inputs 2, 5, 10 with outputs 7, 16, 31: from input 2 to 5 is a rise of 3 and the output rises by 9, so the output rises 3 per unit of input. From 5 to 10 the input rises 5 and the output rises 15, again 3 per unit. So the rule is y equals 3x plus c, and 3 times 2 plus c equals 7 gives c equal to 1. The rule is y equals 3x plus 1. Test: 3 times 10 plus 1 is 31. Correct. Always compute the rise in output per unit rise in input, not the raw difference between rows.

Not every table is a straight-line rule. Inputs 1, 2, 3, 4 with outputs 2, 5, 10, 17: the output differences are 3, 5, 7, not constant, but growing by 2, which signals a square. Compare with the squares 1, 4, 9, 16: each output is one more. The rule is y equals x squared plus 1. Test: 4 squared plus 1 is 17. Correct.

Tables may also run backwards, giving outputs and asking for inputs. With the rule y equals 3x plus 2 and the output 29, solve 3x plus 2 equals 29: 3x is 27, x is 9. Fill the table with 9. A table may also have a missing output, found by substitution, and a missing input, found by solving.

Zero and negative inputs belong in tables too, and they expose wrong rules. For y equals 3x plus 2, input 0 gives 2 — the constant on its own — and input negative 1 gives negative 1. If a proposed rule gives the wrong output at x equals 0, its constant is wrong; that single check settles most disputes about the constant.

Take this section's questions now: reading a rule off consecutive and non-consecutive inputs, spotting a squared rule, and filling missing cells both ways.

## Subtopic: Formulae and Equations: Finding Inputs

A formula gives the output in terms of the input: y equals 3x plus 2. Substituting an input is forwards: x equals 7 gives 21 plus 2, which is 23. Substitution respects the order of operations, so the multiplication happens before the addition, exactly as the flow diagram shows.

Given the output, the formula becomes an equation. y equals 32: 3x plus 2 equals 32. Solving it is the flow diagram in reverse. Undo the plus 2 by subtracting 2 from both sides: 3x equals 30. Undo the times 3 by dividing both sides by 3: x equals 10. Check: 3 times 10 plus 2 is 32. Every equation you solve this year is a flow diagram run backwards, and every step is an inverse operation applied to both sides.

With negatives the mechanics are identical. y equals 2x minus 5 and y equals negative 11: 2x minus 5 equals negative 11; add 5 to both sides, 2x equals negative 6; divide by 2, x equals negative 3. Check: 2 times negative 3 is negative 6, minus 5 is negative 11. Correct.

A squared rule may have two inputs for one output. y equals x squared minus 1 and y equals 24: x squared equals 25, so x is 5 or negative 5, because both square to 25. A flow diagram with a "square" box cannot be run backwards to a single input unless the question restricts x to positive values. State both inputs unless told otherwise.

Formulae in context carry names. The cost C in rand of k kilometres in a taxi is C equals 3k plus 2. For k equal to 15, C is 47. For C equal to 92, 3k equals 90 and k is 30 kilometres. The perimeter of a square with side s is P equals 4s; for P equal to 26, s is 6,5. The letters change; the method does not.

Some rules combine three operations. "Multiply by 2, subtract 3, then divide by 5": y equals the quantity 2x minus 3, over 5. For y equal to 3: multiply both sides by 5 to undo the division, 2x minus 3 equals 15; add 3, 2x equals 18; divide by 2, x equals 9. Check forwards: 18 minus 3 is 15, over 5 is 3. Three boxes, undone in reverse order.

This section's questions are available now: substitution for outputs, solving for inputs in reverse order, and the squared rule with two inputs.

## Subtopic: Choosing a Representation and the Error Museum

The four representations suit different jobs. A flow diagram is best for computing a single output and for seeing the order of operations. A table is best for spotting the rule and for checking it on several inputs. A formula is the general statement and the most compact. An equation is a formula with the output fixed, used to recover an input. The same rule — times 3, plus 2 — lives in all four, and you should be able to move between them without changing the rule.

Moving between them: from the diagram "times 3, plus 2" to the formula y equals 3x plus 2; from the formula to a table by substituting 0, 1, 2, 3; from the table back to the formula by the differences; from the formula to an equation by setting y to a value. Each move is a line of working and a mark.

The error museum for this topic has five exhibits. One: operations applied in the wrong order — reading y equals 3x plus 2 as "add 2, then times 3" and getting 18 for input 4. Two: undoing in the forward order — dividing 20 by 3 before subtracting 2. Three: a rule read from one row — y equals 5x fits input 1, output 5, and nothing else. Four: raw differences used when inputs are not consecutive — the outputs 7, 16, 31 for inputs 2, 5, 10 rise 9 and 15, not 3, and the rate per unit must be computed. Five: a single answer for a squared rule — x squared equals 25 has two solutions.

Layout for marks: for an output, write the substitution with brackets around the input, then the arithmetic. For an input, write the equation, then one inverse operation per line applied to both sides, then the check by substitution. For a rule, write the differences, the rate per unit input, the constant from the x equals 0 check or one row, and the test on another row.

A final habit: whenever you find an input, substitute it back. The check costs a line and catches every reversed-order slip, because a wrong input will not reproduce the output.

The questions for this section are ready: moving between representations, the five exhibits of the museum, and the substitution check.

# Part 2 — Simplifier

Now the same ideas again through a sausage machine, socks and shoes, and a bit of detective work on a table — plain words, same rules.

## Subtopic: The Sausage Machine

Imagine a machine on a table. You drop a number in the top, it clanks through some gears, and a new number drops out the bottom. The number in is the input. The gears are the rule. The number out is the output. A flow diagram is just a drawing of the machine with each gear shown as a box.

Our machine has two gears: "times 3", then "plus 2". Drop in 4: the first gear makes 12, the second makes 14. Drop in 0: 0, then 2. Drop in negative 2: negative 6, then negative 4. Drop in 10: 30, then 32. Whatever you drop in, the machine does the same two things in the same order.

The order of the gears is the whole personality of the machine. Swap them — "plus 2", then "times 3" — and 4 becomes 6 and then 18. Same gears, different machine. In a formula, the machine "times 3 then plus 2" is written 3x plus 2, and the machine "plus 2 then times 3" is written 3 times the quantity x plus 2, with the bracket telling you the adding happened first. Read the bracket as "do me first".

Machines can have other gears. "Square" is a gear: drop in 5, out comes 25. "Subtract 1 then times 4": drop in 6, out comes 5, then 20. And a machine can have a gear missing, with a label asking you to work out what it is. If 4 goes in and 14 comes out, and the first gear is "times 3", then 12 became 14 — the missing gear is "plus 2". Always test it with a second input: 1 becomes 3 becomes 5. Yes.

Keep the machine in mind and try the questions for this part: dropping numbers in, reading the order of the gears, and finding a missing gear.

## Subtopic: Running the Machine Backwards

Now someone shows you an output and asks what went in. You run the machine in reverse — and the rule for reversing is socks and shoes. You put socks on first and shoes second; to undo it, shoes come off FIRST, then socks. Undo the last gear first.

Machine "times 3, then plus 2". Output 20. The last gear was "plus 2", so undo it first: 20 minus 2 is 18. Then undo "times 3": 18 divided by 3 is 6. The input was 6. Prove it by running forwards: 6, 18, 20. Yes.

Each gear has an undo. Adding is undone by subtracting. Multiplying is undone by dividing. Squaring is undone by square-rooting — with a catch we will get to. Reverse the order, swap each gear for its undo, and run.

What happens if you undo in the wrong order? Output 20, divide by 3 first: 6,666..., then subtract 2: 4,666... An ugly, un-whole number. That ugliness is a warning light. Exam machines almost always have tidy inputs, so if your answer is a mess, you probably took the socks off before the shoes.

Here is the catch with squaring. Machine "square, then subtract 1". Output 24. Undo the subtract: 25. Undo the square: what squared gives 25? Both 5 and negative 5. Two inputs give the same output, because the squaring gear throws away the sign. So a machine with a square gear can have two answers when run backwards, and you should give both unless the question says the input is positive.

This backwards run has a name in algebra: solving an equation. 3x plus 2 equals 20 is the sentence "the machine gave 20; what went in?" Subtract 2 from both sides, divide both sides by 3, x is 6. Same socks, same shoes.

Hold the socks-and-shoes picture and try this part's questions: which gear to undo first, what each undo is, and the square gear with two answers.

## Subtopic: Reading a Table Like a Detective

A table is a list of inputs with their outputs, and the machine is hidden. Your job is to work out the gears. Inputs 1, 2, 3, 4; outputs 5, 8, 11, 14. Clue one: every time the input goes up by 1, the output goes up by 3. So there is a "times 3" gear. Clue two: 1 times 3 is 3, but the output is 5, which is 2 more. So there is a "plus 2" gear after it. Machine: times 3, plus 2. Check on the last row: 4 times 3 plus 2 is 14. Case closed.

When the inputs jump — 2, 5, 10 with outputs 7, 16, 31 — do not use the raw jumps. From 2 to 5 the input went up 3 and the output went up 9: that is 3 per step. From 5 to 10 the input went up 5 and the output went up 15: again 3 per step. So "times 3", and then 2 times 3 is 6, output is 7, so "plus 1". Machine: times 3, plus 1. Check: 10 times 3 plus 1 is 31. Yes.

The best clue in any table is the row with input 0, if you have it, because at 0 the "times" gear does nothing and the output is just the "plus" gear on its own. For times 3 plus 2, input 0 gives 2. If a table has input 0 and output 2, the constant is 2, no detective work needed.

If the output jumps are not the same but grow steadily — 2, 5, 10, 17 with jumps 3, 5, 7 — the machine has a "square" gear. Line the outputs up next to 1, 4, 9, 16 and you see every one is 1 more: machine "square, then plus 1".

And tables can have holes. A missing output: run the machine forwards. A missing input: run it backwards, socks and shoes. With machine "times 3 plus 2" and output 29: 29 minus 2 is 27, over 3 is 9. Fill in 9.

Pocket summary of the lesson. Input, machine, output. The order of the gears is the rule, and a bracket means "do me first". To find an input, undo the last gear first. Squaring gears can give two inputs. To find the rule from a table, find the rise per step for the "times" gear, then use one row — best of all the row with input 0 — for the "plus" gear. And always check by running forwards.

Hold the machine, the socks and shoes, and the detective's two clues, and take the final questions of the lesson: reading rules off tables, filling the holes, and checking forwards.
