Hey — if inputs, outputs, flow diagrams and equations felt like four different topics, here is the calm version: it is one machine, drawn four ways.

A number goes in, the gears do their thing in order, a number comes out. A flow diagram is a picture of the gears. A formula is the same gears in symbols — y equals 3x plus 2 means times 3, then plus 2, and a bracket means "do me first". A table is a list of what came out for several inputs. An equation is the machine with the output already known.

Finding an output: run it forwards, in order. Times 3 then plus 2, input 4, gives 12 then 14.

Finding an input: run it backwards — socks and shoes. Undo the LAST gear first. Output 20: minus 2 gives 18, divide by 3 gives 6. If your answer comes out ugly, you undid in the wrong order. If there is a squaring gear, remember two inputs might work, like 5 and negative 5.

Finding the rule from a table: how much does the output rise per step of input? That is the times gear. Then one row — best of all the input 0 row — gives the plus gear.

And always check by running forwards. Open the practice set and picture the machine. You've got this!
