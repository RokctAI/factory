### subtopic_1 — Patterns with a Constant Difference
**Assistant:** How do I describe a pattern rule in my own words?

**Tutor:** Say where the pattern starts and what happens to get from one term to the next, clearly enough that someone else could continue it without seeing your numbers. For Lebo's savings, a good description is: start at 7 and add 8 each time. That has the start and the step. A weak description is: it goes up. That is true, but it does not say by how much, so nobody could continue it. For the chain message: start at 1 and multiply by 3 each time. For the cans: start at 1, add 2, then add 3, then add 4, and keep adding one more each time. Try to use words like add, subtract, multiply, divide, double, halve, each time and one more than last time. You can test your description by reading it to a friend and asking them to write the next three terms. If they get the same numbers as you, your description works. In Grade 6 you also learn to link the term to its position, such as the term is 8 times the position, take away 1. That is a stronger rule, because it lets you find any term without writing out all the terms before it.

### subtopic_2 — Patterns with a Constant Ratio
**Assistant:** Why do multiplying patterns grow so much faster than adding patterns?

**Tutor:** Because in a multiplying pattern the amount added each time gets bigger and bigger, while in an adding pattern it stays the same. Compare two patterns that both start at 3. Adding 3 each time gives 3, 6, 9, 12, 15, 18. Multiplying by 3 each time gives 3, 9, 27, 81, 243, 729. After six terms, the adding pattern has reached 18, but the multiplying pattern has reached 729. In the multiplying pattern, the gaps are 6, 18, 54, 162 and 486. Each gap is three times the one before. This is why a chain message or a rumour can spread through a whole school so quickly, and why scientists worry when the number of people with an illness starts to double every few days. It is also how savings grow with interest over many years. A useful way to remember it: adding patterns climb a steady staircase, while multiplying patterns ride a rocket. When you see numbers growing slowly and evenly, think adding. When they suddenly shoot up, think multiplying, and check by dividing each term by the one before.

### subtopic_3 — Patterns with a Changing Difference
**Assistant:** How can I tell if a pattern has a changing difference?

**Tutor:** Write the gaps between the terms underneath the pattern, and then look at the gaps. If all the gaps are the same, the pattern has a constant difference. If they are not the same, divide each term by the one before. If all those answers are the same, it has a constant ratio. If neither test works, look closely at the row of gaps, because it often has a pattern of its own. For 1, 3, 6, 10, 15, the gaps are 2, 3, 4, 5. Those gaps go up by 1 each time, so the pattern has a changing difference that follows a rule. For 1, 4, 9, 16, 25, the gaps are 3, 5, 7, 9, which go up by 2 each time. For 2, 3, 5, 8, 12, the gaps are 1, 2, 3, 4. Once you have found the pattern in the gaps, extend the gaps first, and then add each new gap to get the next term. Some patterns are trickier, like 1, 1, 2, 3, 5, 8, where each term is the sum of the two before it. That is a famous pattern called the Fibonacci sequence, and it shows up in pine cones and sunflowers.
