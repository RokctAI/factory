# Part 1 — Expert

This session covers determining input values, output values and rules using flow diagrams and tables, and determining the equivalence of different descriptions of the same relationship: in words, in a flow diagram, in a table and as a number sentence. The anchor is a jumping castle business in Soweto that charges R50 for delivery plus R15 for every hour of hire, and Lebo's savings from the last lesson. The governing idea is that a rule changes every input into an output in the same way, that you can run the rule forwards to find outputs and backwards to find inputs, and that the same rule can be written in four different but equal ways. Using flow diagrams, completing tables, finding rules, working backwards and matching equivalent descriptions are examinable.

## Subtopic: Flow Diagrams: Input, Rule, Output

A flow diagram is like a small machine. A number goes in on the left, called the input. It passes through one or more operations, called the rule. A number comes out on the right, called the output.

The jumping castle costs R15 for each hour, plus R50 for delivery. The flow diagram is: input, the number of hours, then times 15, then plus 50, then output, the cost in rand. For 1 hour: 1 times 15 is 15, plus 50 is 65. The cost is R65. For 2 hours: 30 plus 50 is 80. For 3 hours: 45 plus 50 is 95. For 4 hours: 60 plus 50 is 110.

The order of the operations in a flow diagram matters. Times 15 then plus 50 is not the same as plus 50 then times 15. For 2 hours, plus 50 first would give 52, and times 15 would give 780, which is far too much. Always follow the arrows from left to right.

Another flow diagram: input, times 4, plus 3, output. Input 1 gives 7. Input 2 gives 11. Input 5 gives 23. Input 10 gives 43. Notice that when the input goes up by 1, the output goes up by 4, the number we multiply by. That is a useful clue for later.

The questions for this section are with you now: running a flow diagram forwards to find outputs.

## Subtopic: Finding Inputs and Rules

Sometimes you know the output and need the input. A family paid R350 for the jumping castle. How many hours did they hire it? Work backwards through the flow diagram, using the inverse of each operation in reverse order. The last step was plus 50, so first take away 50: 350 minus 50 is 300. The step before was times 15, so divide by 15: 300 divided by 15 is 20. They hired it for 20 hours. Check: 20 times 15 is 300, plus 50 is 350.

For the times 4, plus 3 machine, which input gives 43? Take away 3 to get 40, then divide by 4 to get 10. The input was 10.

Sometimes you know the inputs and outputs and need the rule. Look at this table: inputs 1, 2, 3, 4 and outputs 8, 14, 20, 26. The outputs go up by 6 each time, so the rule probably starts with times 6. 1 times 6 is 6, but the output is 8, so add 2. Test it on the others: 2 times 6 plus 2 is 14, 3 times 6 plus 2 is 20, 4 times 6 plus 2 is 26. The rule is times 6, plus 2. Now find the output for 7: 42 plus 2 is 44.

If a table has gaps, use the rule to fill them. With times 6, plus 2, an output of 62 comes from an input of 10, because 62 minus 2 is 60, and 60 divided by 6 is 10.

Always test a rule on every pair in the table, not just the first one. A rule that works for one pair might not work for the others.

The questions for this section are with you now: working backwards to find inputs, and finding the rule from a table.

## Subtopic: Four Ways to Show One Rule

The same rule can be described in four ways. In words: the cost is 15 rand for each hour, plus 50 rand for delivery. As a flow diagram: hours, times 15, plus 50, cost. As a table: 1 hour R65, 2 hours R80, 3 hours R95, 4 hours R110. As a number sentence: number of hours times 15 plus 50 equals cost, so for 3 hours, 3 times 15 plus 50 equals 95.

These four descriptions are equivalent: they describe exactly the same relationship. To check whether two descriptions are equivalent, test them with the same inputs. If every input gives the same output in both, they match.

Here is a test. Description A says multiply the position by 8 and subtract 1. Description B is the pattern 7, 15, 23, 31, Lebo's savings. Position 1: 8 minus 1 is 7. Position 2: 16 minus 1 is 15. Position 3: 24 minus 1 is 23. Position 4: 32 minus 1 is 31. They match, so the two descriptions are equivalent. Now we can find any week quickly: week 10 is 80 minus 1, which is 79.

The error museum, four exhibits. One: doing the operations in the wrong order, so 2 hours costs 2 plus 50, times 15, which is R780. Two: working backwards with the same operations instead of their inverses, so R350 becomes 350 plus 50, times 15. Three: finding a rule from only the first pair in the table, such as plus 7 for 1 and 8, which fails for 2 and 14. Four: saying two descriptions match after testing only one input.

The questions for this section are with you now: matching words, flow diagrams, tables and number sentences.

## Subtopic: Work Backwards

Start at the output and undo each step, last step first.

R350: take away 50, then divide by 15. That is 20 hours.

To find a rule, check how much the outputs go up by, then test every pair.

Hold the undo steps in mind and try this part's questions: inputs and rules.

## Subtopic: Same Rule, Different Clothes

One rule can be words, a flow diagram, a table or a number sentence.

Test the same inputs. Same outputs? They are equivalent.

Times the position by 8, take away 1: 7, 15, 23, 31.

Pocket summary of the lesson. A flow diagram takes an input through a rule to an output; follow the operations in order. Work backwards by undoing each step in reverse order. To find a rule from a table, look at how much the outputs change, then test the rule on every pair. Words, flow diagrams, tables and number sentences are equivalent when they give the same outputs for the same inputs.
