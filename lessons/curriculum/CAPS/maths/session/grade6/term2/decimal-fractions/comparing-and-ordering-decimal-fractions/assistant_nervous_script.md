Hey — if comparing decimals feels like a trick, here is the calm version: start on the left and go one place at a time.

Wholes first. If they match, tenths. If they match, hundredths.

Longer does not mean bigger: 0,5 beats 0,25.

Add zeros at the end so the numbers look the same length.

In a swimming race, the smallest time wins the gold medal.

Open the practice set and line up the swimmers' times. You've got this!
