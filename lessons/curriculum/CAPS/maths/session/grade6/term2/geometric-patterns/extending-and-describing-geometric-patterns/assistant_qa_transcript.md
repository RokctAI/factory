### subtopic_1 — Matchstick Patterns
**Assistant:** Why does each new matchstick square add 3 matches and not 4?

**Tutor:** Because the new square borrows one side from the square next to it. A square on its own needs 4 sides: top, bottom, left and right. When you build a second square next to the first, its left side is the first square's right side, which is already there. So you only need to add a top, a bottom and a new right side: 3 matches. Every square after that does the same. That is why the pattern goes 4, 7, 10, 13, going up by 3, even though each square has 4 sides. You can also see the rule in the picture. Look at the very first match on the left. Then every square adds 3 more matches: a top, a bottom and a right side. So for any number of squares, the matches are 3 times the number of squares, plus that 1 match on the left. For 10 squares, 3 times 10 plus 1 is 31. A good habit with any shape pattern is to colour or circle the parts that are new in each picture. Then the rule almost jumps out at you, and you understand why it works rather than just finding numbers.

### subtopic_2 — Growing Shapes and Square Numbers
**Assistant:** How do the pictures help me see that 1, 4, 9, 16 grows by odd numbers?

**Tutor:** Draw the square panels of beads and colour the new beads each time. Going from 1 bead to the 2 by 2 square, you add 3 beads in an L shape around the first bead. Going from 2 by 2 to 3 by 3, you add another L shape: 3 beads along the top, 3 beads down the side, but the corner bead is in both, so it is 5 beads. From 3 by 3 to 4 by 4, the L shape has 4 along the top and 4 down the side, sharing a corner, which is 7 beads. Each L is 2 beads longer than the one before, because the square is one bead wider and one bead taller. That is why the gaps are 3, 5, 7, 9, the odd numbers. The picture explains the numbers. It also gives you a lovely fact: adding the odd numbers in order always makes a square number. 1 plus 3 is 4. 1 plus 3 plus 5 is 9. 1 plus 3 plus 5 plus 7 is 16. Beadwork artists in KwaZulu-Natal use patterns like these all the time, and so do tilers and bricklayers.

### subtopic_3 — Describing and Creating Geometric Patterns
**Assistant:** How can I make up my own geometric pattern that works?

**Tutor:** Start simple. Choose a starting picture, like a single triangle, a cross or a small square of dots. Then choose a clear rule for how it grows, and make sure the rule is the same every time. For example, start with a cross of 5 dots, one in the middle and one on each of four arms, and add one dot to the end of each arm every time. That gives 5, 9, 13, 17, so the rule is add 4 each time. Draw at least three pictures so that someone can see the rule. Then make a table with the picture number and the number of dots. Finally, write a description in words: start with a cross of 5 dots and add one dot to each of the four arms each time. Test your pattern by giving it to a friend without the description and asking them to draw picture 4. If they draw the same thing as you, your pattern is clear. For a harder challenge, make a pattern where the amount added grows each time, like a staircase of blocks: 1, 3, 6, 10. Or a pattern that doubles, like a tree that splits into two branches at every level.
