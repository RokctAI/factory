**Thandi:** Before you move on — the questions that come up again and again with this topic. First: the mean, median and mode of the same data were three different numbers. How can a dataset have three different centres and all of them be right?

**Tutor:** Because "centre" is not one idea — it is three different questions asked of the same data, and each measure answers its own question honestly. The mean answers: if the total were shared perfectly equally, what would each person have? The median answers: what does the person in the middle of the ordered line look like? The mode answers: what happens most often? For the homework data those answers were 19, 18 and 15, and each is correct about its own question. They drift apart precisely when the data is lopsided — a tail of large values inflates the share-out while leaving the middle person and the most common value untouched. So the skilled move in an examination is never to ask which number is "right"; it is to ask which QUESTION the situation is really asking. Sharing costs equally — mean. Describing a typical household — median. Stocking a shop shelf — mode. Name the question, and the measure chooses itself.

***

**Thandi:** A lot of people, under pressure, grab the middle value of the list as it is printed and call it the median. Why is ordering non-negotiable, and is there a fast way to not forget it?

**Tutor:** Ordering is non-negotiable because the median is a statement about position in the SORTED line — the value with half the data below it and half above. In an unsorted list, the printed middle position holds whatever value happened to be typed there; it tells you nothing about halves. Examiners know this slip is common, so they deliberately print data shuffled — treat a shuffled list as a set trap, not an accident. The habit that protects you costs one line: the moment a question says median or quartile, rewrite the data in ascending order before anything else, and tick off each value from the original list as you place it, counting at the end to confirm none went missing. Then find the middle: with an odd count there is one middle value; with an even count there are two, and the median is the number exactly halfway between them. Sort, count, point — in that order, every time.

**Thandi:** With grouped data, why does everyone get told to use the midpoint of each class? Someone always asks whether the answer is then simply wrong.

**Tutor:** The answer is not wrong — it is an estimate, and saying so is part of a full-marks answer. Here is the honest chain of reasoning. The frequency table has thrown the raw marks away: eleven learners sit somewhere from 50 to below 60, and the table cannot say where. To compute anything, each of those learners needs a stand-in value. Choosing 50 for everyone would assume the whole class scraped the bottom of the interval; choosing 59 would assume they all crowded the top. The midpoint, 55, is the balanced assumption — learners below it and learners above it roughly cancel, so the errors largely wash out when you multiply by frequency and add across all the classes. That is why the method is trusted, and also why its answer carries the word estimated: the true mean of the actual forty marks is almost certainly near 58, not exactly 58. Write "estimated mean" in your final statement. It is one word, it is true, and memoranda are written to reward it.

**Thandi:** Last one — the classic lost mark: writing "the modal interval is 12". What is the misunderstanding, and how do you make sure the median interval does not go the same way?

**Tutor:** The misunderstanding is answering with the count instead of the class. Twelve is the frequency — HOW MANY learners are in the fullest class. The modal interval is WHERE they are — the class from 60 up to below 70. The question asks for an interval, so the answer must be an interval; saying the frequency is like answering "where do you live?" with "four people". The same discipline saves the median interval. There, the tempting wrong answer is the cumulative count — 21 — instead of the class it points to. Run the method in words: forty values put the middle at the twentieth and twenty-first; the running totals reach 10 by the end of the second class and 21 by the end of the third, so both middle values sit inside the third class, and the answer is the interval from 50 up to below 60. A quick self-check catches both slips: read your final answer aloud and ask whether it names a range of marks. If it is a bare number, you have reported a count, and the interval is still waiting to be written.
