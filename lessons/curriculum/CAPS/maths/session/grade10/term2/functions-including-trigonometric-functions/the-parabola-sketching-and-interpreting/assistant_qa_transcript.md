**Thandi:** Questions from the class before we close! The first one comes up every single year: what is actually the difference between domain and range, and why do we keep losing marks on it?

**Tutor:** The distinction is simple once you attach it to the picture, and the marks are lost almost entirely because learners write the right idea using the wrong letter. Domain is the set of values you are ALLOWED to feed into the function — the inputs, the left-and-right positions on the graph. Range is the set of values that COME OUT — the outputs, the up-and-down heights the curve actually reaches. For y equals x squared, any real number can be squared, so the domain is all real x. But squaring never produces a negative, so the outputs start at zero and go upward forever: the range is y greater than or equal to zero. Now the marking reality: if you write the range as "x greater than or equal to zero", the marker reads a statement about widths where a statement about heights was required, and it scores nothing even though your understanding may be perfect. So build this habit — before writing a range, ask yourself "how high does this curve go, and how low?", and let the word "high" force the letter y into your hand. One more check that catches errors: for a downward-opening parabola the range must run downward from the turning point, so it uses "less than or equal to". If your inequality points the wrong way for the shape, you have caught yourself before the marker did.

***

**Thandi:** Here's one from the break. Someone said that a bigger number in front of x squared makes the graph "bigger". Is that wrong, and why does it matter?

**Tutor:** It is wrong in a way that quietly costs marks, because the word "bigger" hides what is really happening. What that number does is multiply every single output height. Take y equals x squared and compare it with y equals two x squared. At x equals one, the height goes from one to two. At x equals three, it goes from nine to eighteen. Every point is pulled twice as far from the horizontal axis, so the curve becomes taller for the same sideways distance — and a curve that gets tall quickly must look NARROW, because it reaches any given height sooner. So the correct vocabulary is narrower, or stretched vertically. Now run it the other way with y equals one half x squared. At x equals two, the height drops from four to two; the curve climbs lazily, so it takes a long sideways journey to gain height, and it looks WIDER. Learners often say "smaller", which is doubly misleading — the graph is not smaller, it extends forever in both directions; it is flatter and more spread out. Examiners ask this directly, usually as a comparison question, and they reward the words narrower and wider. Attach it to the vase and the serving dish and the language stops slipping.

***

**Thandi:** This one is a real confession. Somebody wrote that y equals x squared plus four crosses the x-axis at two and negative two, because four is the square of two. What went wrong there?

**Tutor:** Two separate things collided, and both are worth untangling. The first is a method slip: to find where a graph crosses the horizontal axis you must set the height to zero and solve, not look for a number that seems related. Setting zero equals x squared plus four gives x squared equals negative four — and no real number multiplied by itself gives a negative answer, because a negative times a negative is positive and a positive times a positive is positive. So there is no real solution, and the honest answer is that this parabola has no x-intercepts at all. The second thing is that the picture agrees completely, which is your reassurance. The number in front of the squared part is positive, so the bowl is the right way up, and the four lifts its lowest point four units above the horizontal axis. An upright bowl sitting on a shelf four units up simply never reaches the floor. That gives you a rule you can apply on sight, before doing any algebra: when the number in front and the number at the end have the SAME sign, there are no crossings; when they have OPPOSITE signs, there are two. Use the rule to predict, then let the algebra confirm it — and when the algebra hands you a negative square, write the words "no real solutions, therefore no x-intercepts" and collect the mark for knowing it.

***

**Thandi:** Last one, and it is a fair challenge. Why does the syllabus make us sketch these by hand when a calculator or a phone can draw the graph in a second?

**Tutor:** Because the sketch is not the point — the reading is. What the examination is testing is whether you can look at an equation and know, without drawing anything, that this curve opens downward, turns at a height of two, is narrow rather than wide, and never touches the horizontal axis. That skill is what lets you interpret a graph you have never seen, check whether an answer is plausible, and later solve inequalities by reading where one curve sits above another. A picture on a screen gives you the answer to one question; the ability to read parameters gives you the answer to every question of that type. There is a practical reason too. Almost all the marks in a sketching question are awarded for the LABELLED features — the intercepts, the turning point, the shape — rather than for the artistic quality of the curve, so a learner who calculates those four things and draws a rough but correctly labelled sketch scores nearly everything, while a beautiful unlabelled curve scores very little. And the habit pays forward: in Grade 11 the same reading skill handles the shifted parabola with its horizontal movement, and in matric it becomes the foundation of curve sketching with calculus. Learn to read the equation now, and the drawing takes care of itself.
