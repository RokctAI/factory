Hey — if counting days feels long, here is the calm version: count the jumps.

Same month? Subtract the dates. 10 minus 3 is 7 days.

Different months? Go to the end of the first month, then add the rest.

Use the real number of days in each month.

New year? Stop at 31 December, then carry on into January.

Open the practice set and count the jumps one month at a time. You've got this!
