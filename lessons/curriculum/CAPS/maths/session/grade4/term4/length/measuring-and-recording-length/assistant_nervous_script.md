Hey — if measuring feels fiddly, here is the calm version: choose, start, read, write.

Choose the unit: mm for tiny, cm for small, m for rooms, km for far.

Start at the 0 mark on the ruler.

Read the centimetres, then the little millimetre marks.

Write the unit, and change to the same unit before you compare.

Open the practice set and measure each one carefully. You've got this!
