Hey — if shape patterns make you feel lost, here is the calm version: look at what was added.

Line the pictures up. Ask what changed from one to the next. Matchstick squares: one more square, 3 more sticks.

Count something in each picture and write the numbers down. 4, 7, 10, 13.

Say the rule in words: add 3 each time. If you can, say it from the picture number too: 3 times the number plus 1.

Some patterns grow by more each time, like 1, 3, 6, 10. That is still a pattern.

Make one of your own and see if a friend can continue it.

Open the practice set and draw the next picture. You've got this!
