Hey — if all the shape names blur together, here is the calm version: count the straight sides.

A flat shape with straight sides and no gaps is a polygon. 3 sides triangle, 4 quadrilateral, 5 pentagon, 6 hexagon, 7 heptagon, 8 octagon.

Turning or stretching a shape does not change its name.

All sides equal and all corners equal? Regular. Otherwise irregular. The name stays the same either way.

A circle is round with no corners, so it is not a polygon. It is just a circle.

Open the practice set and count the sides of each shape. You've got this!
