# Part 1 — Expert

This session covers investigating and extending numeric patterns involving a constant difference or a constant ratio, and patterns of learners' own creation, and describing the observed rules in words. The anchor is a money box in Umtata that receives R15 every week, a theatre with rows of 12, 15, 18 and 21 seats, and a science lesson where a population doubles every hour from 3 to 6 to 12 to 24. The governing idea is that a constant-difference pattern adds the same number each time and a constant-ratio pattern multiplies by the same number each time, that subtracting or dividing neighbours reveals which, and that a rule described in words should let anyone continue the sequence. Extending both kinds of pattern, describing the rule and creating a pattern are examinable.

## Subtopic: Constant Difference Patterns

A numeric pattern is a list of numbers that follows a rule. The simplest rule adds the same number each time. The money box starts with R20 and gets R15 every week: 20, 35, 50, 65, 80. The difference between neighbours is always 15, so this is a constant-difference pattern. To extend it, keep adding 15: 95, 110, 125.

To find the difference, subtract each number from the one after it. 35 minus 20 is 15, 50 minus 35 is 15, 65 minus 50 is 15. Check at least two pairs before you trust the rule. The theatre rows 12, 15, 18, 21 have a difference of 3; the next rows have 24 and 27 seats.

Constant-difference patterns can go down. 100, 92, 84, 76 subtracts 8 each time; the next is 68. A pattern that counts down to zero or below is still a constant-difference pattern, and the difference is simply negative, though in Grade 4 we say subtract 8 each time rather than talk about negative numbers.

Extending backwards means undoing the rule. Before 20 in the money box pattern would be 20 minus 15, which is 5. Before 12 in the theatre would be 9. Patterns do not have to start where the question starts; sometimes you are asked what came before the first number given.

The questions for this section are with you now: finding a constant difference, extending forwards and backwards, and patterns that go down.

## Subtopic: Constant Ratio Patterns

A second kind of rule multiplies by the same number each time. The science lesson population starts at 3 and doubles every hour: 3, 6, 12, 24, 48. Each number is 2 times the one before, so this is a constant-ratio pattern with ratio 2. To extend it, keep doubling: 96, 192.

To find the ratio, divide each number by the one before it. 6 divided by 3 is 2, 12 divided by 6 is 2, 24 divided by 12 is 2. The pattern 5, 15, 45, 135 has a ratio of 3, because 15 divided by 5 is 3 and 45 divided by 15 is 3. The next number is 135 times 3, which is 405.

Constant-ratio patterns grow much faster than constant-difference patterns. Compare adding 3 each time from 3 with multiplying by 3 each time from 3. Adding gives 3, 6, 9, 12, 15, 18. Multiplying gives 3, 9, 27, 81, 243, 729. After five steps the adding pattern has reached 18 and the multiplying pattern has passed 700. That is why populations, savings with interest and rumours spread so fast.

Constant-ratio patterns can shrink by dividing. 800, 400, 200, 100 halves each time; the next is 50. Going backwards in a ratio pattern means dividing instead of multiplying: before 3 in the doubling pattern would be 3 divided by 2, which is one and a half, so in whole-number patterns we usually stop at the first number given.

The questions for this section are with you now: finding a constant ratio by dividing, extending a multiplying pattern, and seeing how fast it grows.

## Subtopic: Which Kind Is It, and Make Your Own

To tell the two kinds apart, test both. Subtract neighbours: if every difference is the same, it is constant difference. Divide neighbours: if every ratio is the same, it is constant ratio. For 2, 4, 6, 8 the differences are all 2, so it adds. For 2, 4, 8, 16 the differences are 2, 4, 8, not constant, but the ratios are all 2, so it multiplies. The two patterns share their first two numbers and then part company.

Some patterns are neither. 1, 4, 9, 16, 25 has differences 3, 5, 7, 9 and ratios that change; it is the square numbers, each the picture number times itself. 1, 1, 2, 3, 5, 8 adds the two numbers before. Such patterns are still patterns with rules, as we saw with the staircase in geometric patterns, but they are not constant difference or constant ratio.

Describe the rule in words so that someone else can continue the pattern. Start at 20 and add 15 each time. Start at 3 and double each time. Start at 800 and halve each time. A good description names the starting number and the rule, because the rule alone does not fix the pattern: add 15 from 20 and add 15 from 7 are different sequences.

Make your own patterns of both kinds. Choose a start and an amount to add: 7, 11, 15, 19, 23. Choose a start and an amount to multiply by: 4, 12, 36, 108. Swap with a friend, who must find your rule and write the next two numbers. If the friend cannot, write your rule out in words and compare.

The error museum, four exhibits. One: calling 2, 4, 8, 16 a constant-difference pattern because it starts like 2, 4, 6, 8; the differences change, the ratios are constant. Two: finding the ratio by subtracting; the ratio is found by dividing each number by the one before. Three: describing a pattern by the rule alone; add 15 from 20 and add 15 from 7 are different, so name the start. Four: extending backwards by applying the rule forwards; going back means undoing the rule.

The questions for this section are with you now: testing a pattern by subtracting and by dividing, recognising patterns that are neither kind, and creating patterns with a clear rule.

# Part 2 — Simplifier

Now the same lesson again with the money box, the theatre seats and the doubling bacteria — plain words, same facts.

## Subtopic: Adding the Same Each Time

The money box starts with R20 and gets R15 every week. 20, 35, 50, 65, 80. Each number is 15 more than the last. Next: 95.

Find the difference by subtracting. 35 minus 20 is 15. 50 minus 35 is 15. Same every time, so add 15.

Going down works too. 100, 92, 84, 76: subtract 8 each time. Next is 68. Going backwards, undo the rule: before 20 is 5.

Keep the money box in mind and try the questions for this part: constant difference patterns.

## Subtopic: Multiplying the Same Each Time

Bacteria: 3, 6, 12, 24, 48. Each number is double the one before. Next: 96.

Find the ratio by dividing. 6 divided by 3 is 2. 12 divided by 6 is 2. Same every time, so multiply by 2.

Multiplying patterns race ahead. Add 3 from 3: 3, 6, 9, 12, 15. Multiply by 3 from 3: 3, 9, 27, 81, 243.

Hold the doubling bacteria in mind and try this part's questions: constant ratio patterns.

## Subtopic: Which One, and Yours

Test both ways. Subtract: all the same? It adds. Divide: all the same? It multiplies. 2, 4, 6, 8 adds 2. 2, 4, 8, 16 multiplies by 2.

Some patterns are neither, like 1, 4, 9, 16. Still a pattern, with a different rule.

Make your own. Say the start and the rule: start at 7, add 4. Start at 4, multiply by 3. Give it to a friend to continue.

Pocket summary of the lesson. A constant-difference pattern adds the same number each time; find it by subtracting neighbours. A constant-ratio pattern multiplies by the same number each time; find it by dividing neighbours, and it grows much faster. Some patterns are neither. Describe a pattern by its starting number and its rule, extend backwards by undoing the rule, and make your own clear enough for a friend to continue.

Hold the two tests in mind and take the final questions of the lesson: telling the kinds apart and making your own.
