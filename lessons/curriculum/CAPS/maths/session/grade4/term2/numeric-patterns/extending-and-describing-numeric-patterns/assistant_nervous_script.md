Hey — if number patterns make your head spin, here is the calm version: ask whether the pattern adds or multiplies.

Subtract neighbours. Same answer every time? It adds that much. 20, 35, 50: add 15.

Divide neighbours. Same answer every time? It multiplies by that. 3, 6, 12, 24: multiply by 2.

To go forwards, do the rule. To go backwards, undo it.

Describe your pattern with its start and its rule, so a friend can continue it.

Open the practice set and test each pattern both ways. You've got this!
