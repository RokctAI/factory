Today we use flow diagrams and tables to work with number patterns. A table lists inputs and outputs side by side, a flow diagram shows the rule as a machine, and a number sentence writes the rule with a box. We learn to complete a table from a rule, to find the rule from a table, to fill in missing inputs and outputs, and to check that a rule in words, a diagram, a table and a number sentence all describe the same pattern. We use pocket money, taxi fares and a school tuck shop price list.
