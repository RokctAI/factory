# Part 1 — Expert

This session covers determining input values, output values and rules for numeric patterns using flow diagrams and tables, and determining the equivalence of descriptions presented verbally, in a flow diagram, in a table and by a number sentence. The anchor is a taxi in Soweto charging R12 per passenger plus a R5 bag fee, a tuck shop selling vetkoek at R6 each, and pocket money of R20 a week plus R50 that was already saved. The governing idea is that the same rule can be shown as a flow diagram, a table of inputs and outputs, a sentence in words and a number sentence, and that moving between these forms and checking they agree is the skill. Completing tables, finding rules from tables, running flow diagrams forwards and backwards and matching equivalent descriptions are examinable.

## Subtopic: Tables from Rules

A table has two rows or two columns: inputs and outputs. The vetkoek rule is times 6, because each vetkoek costs R6. Inputs 1, 2, 3, 4, 5 vetkoek give outputs 6, 12, 18, 24, 30 rand. Filling the table from the rule is the forwards direction: apply the rule to each input and write the result beside it.

Two-step rules fill tables the same way. The taxi charges R12 per passenger plus R5 for the bags, so the rule is times 12 then plus 5. Inputs 1, 2, 3, 4 passengers give 17, 29, 41, 53 rand. Check one: 3 times 12 is 36, plus 5 is 41. The outputs rise by 12 each time, which is the multiplier, and the plus 5 shifts the whole column up.

Tables do not have to list inputs in order or without gaps. A table might show inputs 2, 5, 10 and 20 for the vetkoek rule, with outputs 12, 30, 60 and 120. The rule is applied to each input on its own; you do not need the inputs in between. This is one advantage of a position rule over an add-each-time rule.

Pocket money: R50 already saved, plus R20 each week. After week 1: 70. Week 2: 90. Week 3: 110. The rule from the week number is times 20 then plus 50. After week 10 the total is 10 times 20 plus 50, which is 250 rand. A table with inputs 1, 2, 3, 10 and outputs 70, 90, 110, 250 shows the rule at work.

The questions for this section are with you now: filling a table from a one-step or two-step rule, including tables with gaps in the inputs.

## Subtopic: Rules from Tables and Missing Values

When a table is given without its rule, find the rule from the outputs. Inputs 1, 2, 3, 4 with outputs 17, 29, 41, 53: the outputs step up by 12, so the rule multiplies by 12; 1 times 12 is 12 but the output is 17, so the rule adds 5. Rule: times 12 then plus 5. Test on input 4: 48 plus 5 is 53. Correct.

A table may have an output missing: inputs 1, 2, 3, 4, 5 with outputs 6, 12, blank, 24, 30. The rule is times 6, so the blank is 18. Or an input missing: input blank gives output 42 under the rule times 6, so the input is 42 divided by 6, which is 7. Missing inputs are found by running the rule backwards.

With a two-step rule, run backwards in reverse order. Taxi output 65: undo the plus 5 to get 60, then undo the times 12 to get 5 passengers. Pocket money total 190: undo the plus 50 to get 140, undo the times 20 to get week 7. Always undo the last step first.

If the inputs in the table do not go up by 1, the differences between outputs are not the multiplier directly. Inputs 2, 4, 6 with outputs 12, 24, 36 step up by 12 in the outputs, but the inputs step up by 2, so the multiplier is 12 divided by 2, which is 6. Check: 2 times 6 is 12. Watch the input steps before you read the differences.

The questions for this section are with you now: finding a rule from a table, filling missing outputs and inputs, and running two-step rules backwards.

## Subtopic: Four Descriptions, One Rule

The same rule can be shown four ways. In words: multiply the number of passengers by 12 and add 5. As a flow diagram: input, times 12, plus 5, output. As a table: inputs 1, 2, 3, 4 with outputs 17, 29, 41, 53. As a number sentence: 12 times box plus 5 equals the fare. Each description contains the whole rule, and you should be able to produce any one from any other.

To check that two descriptions are equivalent, test them on the same inputs. The sentence 12 times box plus 5 and the table above agree on inputs 1 to 4. The sentence 17 times box agrees on input 1 only, giving 34 for input 2 where the table says 29, so it is not equivalent. One disagreement is enough to reject it.

Watch for descriptions that look different but are the same. Add 5 to twelve times the number is the same as times 12 then plus 5. Double the number, multiply by 6, then add 5 is also the same, because doubling and then multiplying by 6 is multiplying by 12. Explain why they agree, not just that they agree on a few inputs.

Choose the form that suits the job. A table is best for reading off many values quickly. A flow diagram is best for running a rule backwards. A number sentence is best for a single calculation with a large input, like the fare for 25 passengers, which is 12 times 25 plus 5, which is 305 rand. Words are best for explaining the rule to someone else.

The error museum, four exhibits. One: undoing the times 12 before the plus 5 when running the taxi rule backwards; undo the last step first. Two: reading the multiplier from output differences when the inputs step by 2; divide the output step by the input step. Three: accepting times 17 as the taxi rule because it fits input 1; a rule must fit every row of the table. Four: filling a table with gaps by adding on from the previous row; apply the rule to each input on its own.

The questions for this section are with you now: writing one rule in four forms, testing equivalence, and choosing the form that suits the task.

# Part 2 — Simplifier

Now the same lesson again with the taxi, the vetkoek and the pocket money — plain words, same facts.

## Subtopic: Fill the Table

A table lists inputs and outputs. Vetkoek at R6 each: inputs 1, 2, 3, 4, 5, outputs 6, 12, 18, 24, 30.

Two-step rules work the same way. Taxi: times 12 then plus 5. Three passengers: 36 plus 5 is 41 rand.

Inputs can skip. Input 20 vetkoek: 20 times 6 is 120 rand. Apply the rule to each input on its own.

Keep the vetkoek in mind and try the questions for this part: filling tables from rules.

## Subtopic: Find the Rule, Find the Gap

Outputs 17, 29, 41, 53 for inputs 1 to 4. Steps of 12, so times 12. 1 times 12 is 12, need 17, so plus 5. Rule: times 12 then plus 5.

Missing output under times 6 for input 3? 18. Missing input for output 42? 42 divided by 6 is 7.

Two steps backwards: undo the last step first. Fare 65: minus 5 is 60, divided by 12 is 5 passengers.

Hold the backwards walk in mind and try this part's questions: rules and gaps in tables.

## Subtopic: Same Rule, Four Outfits

Words: times the passengers by 12 and add 5. Diagram: in, times 12, plus 5, out. Table: 1 to 17, 2 to 29, 3 to 41. Sentence: 12 times box plus 5 equals fare.

Test two rules on the same input. Times 17 gives 34 for input 2, but the table says 29. Not the same.

Pick the form for the job. Table for many values. Diagram for going backwards. Sentence for one big input: 25 passengers is 12 times 25 plus 5, which is 305.

Pocket summary of the lesson. A table lists inputs and outputs; fill it by applying the rule to each input on its own. Find a rule from a table by reading the output step, adjusting for the input step if needed, then fixing the start with a plus or minus, and test every row. Find missing inputs by running the rule backwards, undoing the last step first. Words, a flow diagram, a table and a number sentence can all describe one rule, and they are equivalent only if they agree on every input.

Hold the four outfits in mind and take the final questions of the lesson: equivalent descriptions.
