Today we work with patterns made of numbers only. Some grow by adding the same amount each time, like 5, 9, 13, 17. Some grow by multiplying by the same amount each time, like 3, 6, 12, 24. We learn to tell which kind we are looking at, to extend the pattern forwards and backwards, and to describe the rule in our own words. We use savings in a money box, bacteria doubling in a science lesson and seats in a theatre to see both kinds, and we make patterns of our own.
