Hey — if drawing graphs feels like a lot of rules, here is the calm version: keep it fair and label it.

Pictograph: one same-size picture for each learner, lined up neatly.

Bar graph: groups along the bottom, numbers up the side.

The numbers start at 0 and go up in equal steps.

Every bar is the same width, with equal gaps.

Add a title and labels, then check against your table.

Open the practice set and draw it one bar at a time. You've got this!
