Hey — if data handling sounds big, here is the calm version: ask, count, show, tell.

Ask one clear question with a short list of answers.

Draw one tally line for each answer. The fifth line goes across.

Count the bundles in fives, then add the leftover lines.

Put the totals in a table and check they add up to everyone.

Open the practice set and tally your way through it. You've got this!
