Hey, it's Mandy — I know the moment the difference table grew a second row and three letters appeared at once, this felt like grade eleven coming back to haunt you. It is actually the friendliest question in the whole sequences section, because it never changes shape.

Everything is one table and three sentences. The table first: subtract neighbours, and if the gaps are constant the pattern is linear — done. If the gaps themselves grow by a constant amount, the pattern is quadratic, and that constant gap-of-gaps is the second difference.

Then the three sentences that build T n equals a n squared plus b n plus c. Half the second difference is a. The first gap is 3 a plus b, so b falls out. The first term is a plus b plus c, so c falls out. Solve them in that order — a, then b, then c — and each line hands you one letter. Then test the formula on a term you can see. If it reproduces term three or term four correctly, trust it all the way to term fifty.

The backwards questions are the same skill wearing a mask. Which term equals some value? Set the formula equal to it, solve the quadratic, and keep only a natural number n. A negative root, a fraction like 11,5 — those are the pattern telling you the value is not there, and writing that sentence IS the answer, worth its own mark.

And if an x hides inside the terms, let it ride through the difference table until an equation forms, then substitute back and check the second differences agree.

One table, three sentences, and n must be whole. Every mark in this lesson is reachable. You've got this!
