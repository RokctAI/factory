Today we take functions apart properly: what the formal definition actually demands, and when a function can be run backwards as an inverse. This sits at the heart of Paper 1 — the swap of x and y, the reflection in the line y equals x, and the restriction of a domain are marks the examiners set every single year. We start with the one-input-one-output promise and the vertical line test, build inverses by swapping and solving, see the mirror picture on the diagonal, and finish with the trap the parabola sets and the domain restriction that fixes it.
