Today we lay the two foundation stones of calculus: the limit, which lets a quantity approach a value it never quite reaches, and differentiation from first principles, which turns that limit into a machine for measuring change at a single instant. First principles is a guaranteed question in Paper 1, and every derivative rule you will use for the rest of the year is born here. We start with the hole in a graph and the value everything around it points to, shrink an average gradient into an instantaneous one, and finish with the four-step definition of the derivative applied to the syllabus functions.
