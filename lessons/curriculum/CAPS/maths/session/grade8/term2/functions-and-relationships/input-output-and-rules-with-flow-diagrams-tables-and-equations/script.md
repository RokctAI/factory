# Part 1 — Expert

This session revises the determination of input values, output values and rules using flow diagrams, tables and formulae, and extends the work to equations. A relationship assigns to each input exactly one output according to a rule; the rule may be shown as a flow diagram of operations, as a formula with the output as subject, or as a table of input–output pairs. Finding an output is substitution; finding an input is solving an equation; finding the rule is reading the constant difference and the value at zero. The anchor rule is multiply by three then subtract two, written y equals three x minus two, with input four giving output ten and output nineteen coming from input seven.

## Subtopic: Input, Rule, Output — The Flow Diagram

A flow diagram shows a rule as a sequence of operations applied to an input to produce an output. Draw a box for the input, an arrow labelled with the first operation, an arrow labelled with the second, and a box for the output. The rule multiply by three, then subtract two: input four, multiply by three gives twelve, subtract two gives ten. Output ten. Input zero: zero, then negative two. Input negative one: negative three, then negative five. Input a half: three halves, then negative a half.

Each input produces exactly one output, because the operations are fixed; that is what makes the diagram a rule. Different inputs may give different outputs, and for this rule they always do: no two inputs share an output.

The order of the operations matters. Multiply by three then subtract two is not the same as subtract two then multiply by three. For input four: the first gives ten; the second gives two, then six. The flow diagram makes the order visible — the arrows are read left to right — and when the rule is written as a formula the order of operations must encode the same thing: three x minus two for the first, three bracket x minus two bracket for the second.

A flow diagram can have one operation — add seven; multiply by four; divide by two — or several. A three-step rule: multiply by two, add one, then square. Input three: six, seven, forty-nine. The formula is bracket two x plus one bracket squared, and the bracket records that the squaring came last.

Several inputs at once are shown with a stack of input boxes feeding the same arrows: inputs one, two, three, four give outputs one, four, seven, ten for the anchor rule, and that stack is the table of the next section.

Reading a flow diagram is following arrows; writing one from a rule in words is naming each operation in order. Both are revision from earlier grades, but the operations now include squaring, cubing and roots, and the inputs now include integers, fractions and decimals. Questions on flow diagrams follow now.

## Subtopic: Rule to Formula and Formula to Table

A flow diagram and a formula are the same rule in two notations. Multiply by three then subtract two is y equals three x minus two: x is the input, y is the output, and the formula is the whole diagram in one line, with the order of operations doing the work of the arrows. Add five then multiply by two is y equals two bracket x plus five bracket, and the bracket is essential — two x plus five would be multiply by two then add five.

To translate a diagram into a formula, apply the operations to the letter x in order and simplify only if it does not change the meaning. Divide by two then add three: x over two plus three. Square then subtract one: x squared minus one. Multiply by four, subtract one, then halve: bracket four x minus one bracket over two.

To translate a formula into a diagram, read the order of operations: in three x minus two the multiplication binds to x first, so the diagram is multiply by three, then subtract two. In two bracket x plus five bracket the bracket is done first: add five, then multiply by two. In x squared minus one: square, then subtract one.

A table of values comes from the formula by substitution, as in the equations topic. For y equals three x minus two with inputs one to five: outputs one, four, seven, ten, thirteen. Write it with inputs in the top row and outputs below. Input zero gives negative two, and negative inputs are allowed: negative two gives negative eight.

Other letters: a pattern rule T equals four n minus one is a flow diagram multiply by four then subtract one, with n the input and T the output. A cost formula C equals eight k plus twelve is multiply by eight then add twelve. A formula from geometry, A equals six e squared for the surface area of a cube, is square then multiply by six.

The three forms — diagram, formula, table — carry the same information, and a question may give any one and ask for another. Translating is the skill. Questions on translating follow.

## Subtopic: Finding the Input — Working Backwards and Equations

When the output is known and the input is not, run the flow diagram backwards: reverse the order of the operations and replace each by its inverse. Multiply by three then subtract two, with output ten: undo the subtract two by adding two, twelve; undo the multiply by three by dividing by three, four. The input was four. Output nineteen: twenty-one, then seven. Output negative eight: negative six, then negative two.

Backwards through the diagram is exactly solving the equation three x minus two equals ten with inverses: add two to both sides, three x equals twelve; divide by three, x equals four. The reverse flow diagram and the formal solution are the same steps in two notations, and this is the extension to equations that the lesson title promises: an unknown input turns the formula into an equation.

Add five then multiply by two, output twenty-six: divide by two, thirteen; subtract five, eight. Equation: two bracket x plus five bracket equals twenty-six. Square then subtract one, output fifteen: add one, sixteen; square root, four or negative four. Two inputs, because squaring loses the sign — the reverse of a square has two branches, and both must be reported unless the context rules one out.

Divide by two then add three, output seven: subtract three, four; multiply by two, eight. Equation x over two plus three equals seven.

Some outputs have no input. For multiply by three then subtract two with whole-number inputs, output eleven gives thirteen then thirteen thirds — not a whole number, so if the inputs are restricted to whole numbers there is no input; if any number is allowed, the input is thirteen thirds. Read what inputs are allowed. For square then subtract one, output negative five gives negative four under the root, and no input at all.

Tables with missing inputs are filled by the same backward run. For y equals three x minus two, output twenty-two: twenty-four, eight. Output negative eleven: negative nine, negative three.

Check every backward answer by running it forwards: eight into add five then multiply by two gives twenty-six. Forwards is substitution; backwards is solving; the two confirm each other. Questions on finding inputs follow.

## Subtopic: Finding the Rule from a Table

A table of inputs and outputs can hide its rule, and finding it is the third kind of question. Inputs one, two, three, four with outputs one, four, seven, ten. Look at the step in the outputs as the input rises by one: three each time. The rule multiplies by three. Then check what else is needed: three times one is three, but the output is one, so subtract two. Rule: multiply by three then subtract two; formula y equals three x minus two. Check on another pair: three times four minus two is ten.

The method: constant step in outputs gives the multiplier; the multiplier times an input, compared with its output, gives the constant to add or subtract. The output at input zero, if it is in the table, is that constant directly: for this rule it would be negative two.

Inputs zero, one, two, three with outputs five, seven, nine, eleven: step two, output at zero is five; y equals two x plus five. Inputs two, four, six, eight with outputs seven, thirteen, nineteen, twenty-five: the inputs step by two and the outputs by six, so the multiplier is six over two, three; three times two is six, output seven, so add one; y equals three x plus one. When inputs are not one apart, divide the output step by the input step.

A table whose outputs decrease has a negative multiplier: inputs one, two, three with outputs eight, six, four: step negative two; negative two times one is negative two, output eight, so add ten; y equals ten minus two x.

A table with no constant step is not a multiply-and-add rule. Inputs one, two, three, four with outputs one, four, nine, sixteen: steps three, five, seven — increasing. These are the squares; y equals x squared. Outputs two, five, ten, seventeen are the squares plus one. Recognise squares and cubes when the steps are not constant.

Always verify the rule on every pair in the table, not just the two you used to find it, and state the rule in the form asked — words, flow diagram or formula. Questions on finding the rule follow.

# Part 2 — Simplifier

Now the same rules as stories about a sausage machine on a farm, a photocopier with two settings, and a locked-door puzzle where you know what came out and must work out what went in — stories in which the machine is the rule, and the only thing that changes is which end you are standing at.

## Subtopic: The Sausage Machine

On a farm there is a sausage machine. Meat goes in one end, a handle turns, sausages come out the other end. The machine does the same thing every time: for every kilogram of meat it makes three sausages, and it keeps two sausages back for the dog. Put in four kilograms: twelve sausages, minus two, ten in the tray. That is the flow diagram multiply by three then subtract two, and the machine is the rule.

Everything about this lesson is a question about the machine. What comes out if I put in seven kilograms? Twenty-one minus two, nineteen. That is finding the output. If nineteen sausages came out, what went in? Add back the dog's two, twenty-one; three sausages per kilogram, so seven kilograms. That is finding the input — reversing the machine, which means reversing the order of what it does and undoing each step. And if a new farmhand has lost the instruction card and only has a list of what went in and what came out — one kilogram gave one sausage, two gave four, three gave seven — can he work out what the machine does? Each extra kilogram gives three more sausages, so it multiplies by three; but one kilogram should then give three, and it gave one, so the machine must take two away. He has found the rule.

The formula is the instruction card written in symbols: sausages equal three times kilograms minus two. The table is the farmhand's list. The flow diagram is the machine seen from above. The equation three k minus two equals nineteen is the question what went in, written down.

What the machine will not do is give two different answers for the same input. Four kilograms gives ten sausages, today and tomorrow. That reliability is what makes it a rule, and it is why you can run it backwards with confidence: nineteen sausages came from seven kilograms and from nothing else.

A second machine squares the kilograms and then takes one for the dog. Three kilograms: nine minus one, eight. If fifteen came out, what went in? Sixteen before the dog; four kilograms — or negative four, says the algebra, which the farmer ignores because you cannot put negative meat in a machine. Context closes the branch. Questions on the sausage machine follow.

## Subtopic: The Photocopier With Two Settings

A photocopier has two dials: one multiplies the number of copies, one adds extra copies. Set the dials to times three and plus five, in that order, and ten originals give thirty-five copies. Now a colleague swaps the order of the dials — plus five, then times three — and ten originals give forty-five copies. Same dials, different order, different output. The copier is a flow diagram, and the order of the arrows is the order of the dials.

Written as formulas, the first is three x plus five and the second is three bracket x plus five bracket. The bracket is the colleague's swap: it says do the adding first. A learner who writes three x plus five for the second machine has not read the order, and the copier would prove them wrong by fifteen copies.

Running the copier backwards: the first machine produced fifty copies — how many originals? Undo the plus five: forty-five. Undo the times three: fifteen originals. The second machine produced fifty-one — how many originals? Undo the times three first, because it was done last: seventeen. Undo the plus five: twelve originals. Reversing means the last dial is the first undone.

Now the copier's log sheet, which records originals and copies for the day: five gave twenty, eight gave twenty-nine, twelve gave forty-one. Which setting was used? From five to eight the originals rose by three and the copies by nine — three copies per original, so the times dial was three. Three times five is fifteen, and twenty came out, so the plus dial was five. Setting: times three, plus five. Check on twelve: thirty-six plus five, forty-one. Confirmed.

The copier makes one more point. If you only know that fifty copies came out and nothing about the setting, you cannot find the originals — you need the rule as well as the output. And if you know the setting and the originals, the copies are fixed. Rule plus input gives output; rule plus output gives input; input–output pairs give the rule. Three questions, one machine. Questions on the copier follow.

## Subtopic: Method Summary and Examination Technique

The method. To find an output: follow the flow diagram, or substitute into the formula, with brackets round negative inputs. To find an input: reverse the diagram — last operation undone first, each replaced by its inverse — or write the formula with the known output as an equation and solve with inverses; give both roots for a square. To find a rule: take the step in the outputs over the step in the inputs for the multiplier, compare with one pair for the constant, and verify on every pair; if the steps are not constant, test squares and cubes. To translate: read the order of operations in a formula for the diagram, and apply the diagram's operations to x for the formula.

A typical question: a flow diagram reads multiply by five, then subtract three. Find the outputs for inputs two and negative one, and the input for output thirty-two. Outputs seven and negative eight. Input: thirty-five, then seven.

Another: write the flow diagram for y equals two bracket x minus four bracket and find the input for output ten. Subtract four, then multiply by two. Backwards: five, then nine.

Another: a table has inputs one to four and outputs five, nine, thirteen, seventeen. Give the rule as a formula. Step four; four times one is four, output five, so plus one. y equals four x plus one. Check: four times four plus one, seventeen.

Another: for y equals x squared plus two, find the inputs that give eleven. x squared equals nine; three or negative three.

Another: a cost rule charges thirty rand per ticket plus a booking fee of fifteen rand. Write it as a formula and find how many tickets cost two hundred and twenty-five rand. C equals thirty t plus fifteen. Thirty t equals two hundred and ten; seven tickets.

Errors to avoid. Reading the diagram in the wrong order. Writing two x plus five for add five then multiply by two. Undoing operations in the forward order. Dropping the negative root. Finding a rule from two pairs and not checking the rest. Confusing input and output columns.
