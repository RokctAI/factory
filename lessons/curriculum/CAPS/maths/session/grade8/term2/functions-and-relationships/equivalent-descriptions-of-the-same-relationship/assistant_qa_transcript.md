### subtopic_1 — Six Descriptions of One Relationship
**Assistant:** If the six forms say the same thing, why learn all of them?

**Tutor:** Because each form answers a different kind of question quickly, and examinations ask all the kinds. The verbal description is how a situation arrives — a hall costs five hundred rand plus forty a head — and it is where letters get defined. The flow diagram makes the order of operations unmistakable, which matters when an addition comes before a multiplication. The table gives several specific answers at a glance and is the raw material for a graph. The formula is the complete rule: it gives any output from any input, it can be rearranged, and it can be compared with another formula by algebra to decide equivalence. The number sentence checks one case and shows a claim to be true or false. The equation asks the reverse question — which input gives this output — and is solved with the methods from the equations topic. A learner who can only use one form will be slow or stuck on questions that call for another, while a learner who moves freely between them chooses the fast route every time.

### subtopic_3 — Deciding Whether Two Descriptions Are Equivalent
**Assistant:** Is checking a few inputs enough to prove two descriptions are equivalent?

**Tutor:** It is enough to disprove equivalence — a single input on which the outputs differ settles that the descriptions are different — but it is not a proof of equivalence, because two different rules can agree at some inputs by coincidence. The marked price plus fifteen percent and the marked price plus fifteen rand agree at exactly one hundred rand and nowhere else. For the rules you meet in Grade 8, which multiply and add, agreement at two or three well-chosen inputs is very strong evidence, and it is what you should do first because it is quick. The proof is algebra: write both descriptions as formulas, expand any brackets and collect like terms, and if the two simplify to the same expression they are equivalent for every input. Two bracket n plus one bracket becomes two n plus two, so it is equivalent to two n plus two; three bracket x minus two bracket becomes three x minus six, so it is not equivalent to three x minus two. Numbers to be convinced, algebra to be sure, as the patterns topic put it.

### subtopic_4 — Choosing the Right Form for the Question
**Assistant:** How do I know which form a question wants if it does not say?

**Tutor:** Read what the question is asking for and match it to the form that produces that kind of answer. If it asks for a value of the output for a given input — what does it cost for twenty guests — substitute into the formula or read the table. If it asks for the input that gives a certain output — how many guests for one thousand seven hundred rand — write the equation and solve it. If it asks how the output changes per unit of input — how much more per guest — give the coefficient as a rate. If it asks you to describe or write a rule, give the formula with the letters defined, and the words if asked. If it asks for several values or for something to plot, make a table. If it asks you to check a claim, write the number sentence and evaluate it. When a question asks for a specific form by name, give exactly that form and label it, and when it asks for more than one form, label each. The marks are usually attached to the forms, so unlabelled working loses them.

### subtopic_6 — The Argument About the Chairs
**Assistant:** When two learners' rules look different, how should they settle who is right without a teacher?

**Tutor:** By testing, not arguing. First, each should evaluate both rules at the same few inputs, including an input that is not one of the pattern's first few terms, and compare the outputs. If the outputs differ at any input, the rules are different and at least one is wrong, and checking against the actual pattern shows which. If the outputs agree at every input tried, the rules are probably equivalent, and the second step confirms it: expand any brackets in both formulas and collect like terms, and if the simplified forms are identical the two rules are the same relationship described two ways. Two n plus two and two bracket n plus one bracket pass both tests, so both learners were right and each had counted the chairs in a different but valid way. The habit of settling by evidence rather than by appearance is the whole of this lesson, and it carries into Grade 9, where expressions that look very different turn out to be equal and the only reliable judge is algebra.
