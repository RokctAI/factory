Today we reduce a whole data set to a few numbers that describe it. The mean, median and mode each give a single typical value, and each answers a slightly different question; the range and the extremes say how spread out the data is around that typical value. By the end you will calculate all five from a list, an ordered list, a frequency table or a stem-and-leaf display, choose the measure that fits the data and the question, explain how an extreme value pulls the mean but not the median, and present a summary that an examiner can follow line by line.
