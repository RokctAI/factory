Hey — if shape names feel like a long list to memorise, here is the calm version: count the straight sides and the name follows.

3 sides: triangle. 4 sides: quadrilateral. 5: pentagon. 6: hexagon. 7: heptagon.

Curved outline? Not a polygon.

All sides and all angles the same? Regular. If not, irregular.

Turned around? Same shape, same name.

Open the practice set and count the sides one by one. You've got this!
