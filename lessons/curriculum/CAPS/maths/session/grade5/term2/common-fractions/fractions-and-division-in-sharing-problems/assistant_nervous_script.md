Hey — if fractions and division seem like two different scary things, here is the calm version: they are the same thing.

3/4 means 3 shared by 4. That is all.

Sharing and something is left over? If it can be cut, cut it. The leftover goes over the number of people.

How many quarter cups in 3 cups? 4 in each cup, so 12.

Draw it if you are unsure. Pizzas, oranges and cups make it easy to see.

Open the practice set and share it out. You've got this!
