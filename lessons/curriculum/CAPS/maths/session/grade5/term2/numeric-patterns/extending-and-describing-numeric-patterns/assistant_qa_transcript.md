### subtopic_1 — Constant Difference Patterns
**Assistant:** How do I know whether a pattern adds the same amount or multiplies by the same number?

**Tutor:** Test both ideas on at least three numbers. First, find the differences by subtracting each number from the next. If every difference is the same, the pattern has a constant difference. Take 5, 10, 15, 20: the differences are all 5, so the rule is add 5. Now take 5, 10, 20, 40: the differences are 5, 10 and 20, which are not the same. So try multiplying. 5 times 2 is 10, 10 times 2 is 20, and 20 times 2 is 40. Each number is double the one before, so the pattern has a constant ratio of 2. Notice that both patterns start with 5 and 10. If you looked at only those two numbers, you could not tell them apart. That is why you need at least three numbers. Another clue is speed. Constant difference patterns grow steadily, like steps on a staircase. Constant ratio patterns grow faster and faster, like Ayanda's message, which goes from 27 to 81 to 243 learners. When you have chosen a rule, test it on every number you were given, not just the first few.

### subtopic_2 — Constant Ratio Patterns
**Assistant:** Why should my rule say where the pattern starts?

**Tutor:** Because the same rule can make many different patterns, and the start tells you which one you mean. The rule add 15 each time could give 15, 30, 45, or 2, 17, 32, or 100, 115, 130. All three follow add 15, but they are different patterns. If you tell a friend only add 15, they cannot write your pattern. If you say start at 15 and add 15 each time, there is only one pattern they can write. The same is true for constant ratio patterns. Multiply by 3 each time could be 1, 3, 9, 27, or 2, 6, 18, 54. The start changes every number in the pattern. A clear description has two parts: where to begin and what to do each time. For a pattern that goes down, say so clearly too: start at 1 000 and subtract 120 each time. Some people also describe the pattern using the position, such as the number in each place is the place number times 15. That works for Ayanda's savings because the pattern starts at 15. Both kinds of description are good, as long as a friend could use yours to write the pattern correctly.

### subtopic_3 — Describing Rules and Making Your Own
**Assistant:** Can a pattern keep going forever?

**Tutor:** A pattern of numbers can keep going forever, but a pattern in a real story usually has a limit. The numbers 15, 30, 45, 60 can go on as long as you like. But Ayanda's water tank starts with 1 000 litres and loses 120 litres a day. After 8 days, 8 times 120 litres, which is 960 litres, have been used, so 40 litres are left. On day 9 the family would need 120 litres but only 40 are in the tank, so the pattern cannot continue as before. The message pattern has a limit too. If Ayanda's school has 600 learners, then on day 6 the pattern says 243 new learners hear it, so 364 learners have heard it altogether. On day 7 the pattern says 729 new learners, which is more than the whole school. There are not enough learners left to keep multiplying by 3. So when a pattern comes from a story, extend the numbers, but also ask whether each answer still makes sense. This habit of checking answers against the real world is important in maths, especially when you use patterns to make predictions.
