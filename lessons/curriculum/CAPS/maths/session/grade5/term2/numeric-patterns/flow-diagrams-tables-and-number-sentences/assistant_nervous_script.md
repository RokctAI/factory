Hey — if tables and flow diagrams feel like too many boxes, here is the calm version: they are two ways of showing the same rule.

A flow diagram: number in, do the boxes, number out.

A table: inputs on top, outputs below, each pair one trip through the machine.

Gap in the table? Put that input through the rule.

Need the rule? Compare the jumps, then fix the start.
