# Part 1 — Expert

This session covers investigating and extending numeric patterns with a constant difference or a constant ratio, including patterns of your own creation, and describing the rules in your own words. The anchor is a Grade 5 learner in Durban, Ayanda, who saves money each week, watches a message spread through her school, and keeps track of a water tank at home. The governing idea is that you find the rule of a number pattern by comparing each number with the one before it: if the same amount is added or subtracted, the pattern has a constant difference, and if it is multiplied or divided by the same number, it has a constant ratio. Extending patterns, finding missing numbers, describing rules and creating patterns are examinable.

## Subtopic: Constant Difference Patterns

Ayanda saves R15 every week. After week 1 she has R15, after week 2 R30, then R45, then R60. Each number is 15 more than the one before, so the pattern has a constant difference of 15. Extending it gives R75, R90 and R105.

A constant difference can also make a pattern go down. The family's water tank holds 1 000 litres, and they use 120 litres a day. The amounts left are 1 000, 880, 760, 640 litres. Each number is 120 less than the one before. The next numbers are 520, 400 and 280.

To find a constant difference, subtract each number from the next one. In 250, 500, 750, 1 000, the difference is 250 every time, so the next number is 1 250. In 93, 86, 79, 72, the difference is 7 every time and the pattern goes down, so the next number is 65.

Missing numbers in the middle work the same way. In 14, 21, ___, 35, 42, the difference is 7, so the missing number is 28. Check that it fits on both sides: 21 plus 7 is 28, and 28 plus 7 is 35.

The questions for this section are with you now: extending patterns that go up or down by the same amount and finding missing numbers.

## Subtopic: Constant Ratio Patterns

A message is passed around Ayanda's school. On day 1, 1 learner knows it. Each learner tells 3 new learners the next day, so the number who hear it on each day is 1, 3, 9, 27, 81. Each number is 3 times the one before. This pattern has a constant ratio: you multiply by the same number each time.

Doubling is a constant ratio too. A plant in Ayanda's garden has 2 leaves, then 4, then 8, then 16. Multiply by 2 to get 32 and then 64. Multiplying by 10 makes 4, 40, 400, 4 000, and the next number is 40 000.

A constant ratio can also make a pattern go down, by dividing. Ayanda has 64 sweets and gives away half each day: 64, 32, 16, 8, 4. Each number is the one before divided by 2. In 5 000, 500, 50, each number is the one before divided by 10, so the next number is 5.

To tell the two kinds apart, look at the first three numbers. In 2, 4, 6, 8 the difference is always 2, so it is a constant difference. In 2, 4, 8, 16 the differences are 2, 4 and 8, so it is not a constant difference; but each number is double the one before, so it has a constant ratio of 2. Both patterns start 2, 4, so you need at least three numbers to be sure.

The questions for this section are with you now: extending multiplying and dividing patterns, and telling a constant difference from a constant ratio.

## Subtopic: Describing Rules and Making Your Own

Describe the rule in your own words, clearly enough that a friend could continue the pattern without seeing it. A good description says where the pattern starts and what happens each time: start at 15 and add 15 each time. Start at 1 and multiply by 3 each time. Start at 1 000 and subtract 120 each time.

A rule that uses the position of a number lets you jump ahead. Ayanda's savings after week 10 are 10 times 15, which is R150. After week 20 she has 20 times 15, which is R300. You do not need to write out every week.

Making your own pattern helps you understand patterns. Choose a starting number, choose a rule, and write the first five numbers. Start at 7 and add 9 each time: 7, 16, 25, 34, 43. Start at 3 and multiply by 2 each time: 3, 6, 12, 24, 48. Then swap with a friend and find each other's rules.

When a pattern is in a story, the numbers must make sense. A water tank cannot go below 0 litres, so the tank pattern stops after day 8, when 40 litres are left.

The error museum, four exhibits. One: adding instead of multiplying, so 1, 3, 9, 27 is continued with 33 instead of 81. Two: finding the difference from only the first two numbers, so 2, 4, 8 is called add 2 and continued with 10 instead of 16. Three: adding when the pattern goes down, so 93, 86, 79 is continued with 86 instead of 72. Four: describing a rule without a start, such as add 15, which could start anywhere.

The questions for this section are with you now: describing rules in words, jumping to a far-off number, and creating your own patterns.

# Part 2 — Simplifier

Now the same lesson again with Ayanda's savings, the message and the water tank — plain words, same facts.

## Subtopic: Same Jump Each Time

R15, R30, R45, R60. Add 15 each time. Next: R75.

1 000, 880, 760 litres. Take away 120 each time. Next: 640.

Keep the same-jump idea in mind and try the questions for this part: constant differences.

## Subtopic: Times the Same Each Time

1, 3, 9, 27. Times 3 each time. Next: 81.

2, 4, 8, 16. Double each time. Next: 32.

64, 32, 16. Halve each time. Next: 8.

Hold the times-the-same idea in mind and try this part's questions: constant ratios.

## Subtopic: Say It and Make One

Say the start and the rule: start at 15 and add 15 each time.

Week 10: 10 times 15 is R150.

Pocket summary of the lesson. Compare each number with the one before it. If the same amount is added or taken away, the pattern has a constant difference. If it is multiplied or divided by the same number, it has a constant ratio. Look at at least three numbers before you decide. Describe a rule by giving the start and what happens each time. Use the position to jump ahead, and make up your own patterns to practise.

Hold the start-and-rule description in mind and take the final questions of the lesson: describing and creating patterns.
