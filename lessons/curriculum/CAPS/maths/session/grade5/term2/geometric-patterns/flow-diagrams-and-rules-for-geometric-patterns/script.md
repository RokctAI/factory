# Part 1 — Expert

This session covers determining input values, output values and rules using flow diagrams, and determining the equivalence of rules given in words, in a flow diagram and by a number sentence. The anchor is a primary school in Kimberley setting out rows of tables for a fundraising supper, where the number of chairs depends on how many tables are pushed together. The governing idea is that a flow diagram is a rule machine: a number goes in, the steps are done in order, and a number comes out, and the same machine can also be run backwards. Finding outputs, finding inputs, finding the rule, and matching a rule written in different ways are examinable.

## Subtopic: Flow Diagrams: Input, Rule, Output

The school uses long tables. One table on its own seats 6 people: 2 on each long side and 1 at each end. When two tables are pushed together end to end, the two middle ends disappear, so the row seats 4 on each long side and 1 at each end, which makes 10. Three tables seat 14, and four tables seat 18.

Each extra table adds 4 chairs, 2 on each side. So the rule is: number of tables times 4, then add 2 for the two ends. Check with three tables: 3 times 4 is 12, and 12 plus 2 is 14. Correct.

A flow diagram shows this rule as a row of boxes joined by arrows. The input, the number of tables, goes in on the left. The first operation box says times 4. The second operation box says plus 2. The output, the number of chairs, comes out on the right. For an input of 5, the first box gives 20 and the second box gives 22, so a row of 5 tables needs 22 chairs.

A flow diagram is useful because you can put many inputs through the same rule and list the outputs in order. Inputs 6, 7 and 8 give outputs 26, 30 and 34. The outputs go up by 4 each time, because each extra table adds 4 chairs.

The questions for this section are with you now: putting inputs through a flow diagram and finding the outputs.

## Subtopic: Finding Inputs and Rules

Sometimes you know the output and need the input. The principal has 30 chairs. How many tables make a row that uses all 30 chairs? Run the flow diagram backwards: undo each step, starting from the last one. The last step was plus 2, so take away 2: 30 minus 2 is 28. The step before was times 4, so divide by 4: 28 divided by 4 is 7. A row of 7 tables uses 30 chairs. Check by going forwards: 7 times 4 is 28, and 28 plus 2 is 30.

The opposite of plus is minus, and the opposite of times is divided by. When you work backwards, you use the opposite operations in the opposite order.

Sometimes you know some inputs and outputs and must find the rule. The school also has a second kind of table, and a learner records the chairs for rows of them: input 1, output 5; input 2, output 8; input 3, output 11. The outputs go up by 3, so the rule starts with times 3. Input 1 times 3 is 3, but the output is 5, so you must add 2. The rule is times 3, then plus 2. Test it on input 3: 3 times 3 is 9, and 9 plus 2 is 11. It works.

Always test a rule on every pair you know. A rule that works for only one pair is not the rule.

The questions for this section are with you now: working backwards to find an input and finding a rule from a table of inputs and outputs.

## Subtopic: One Rule, Three Ways

The same rule can be written in three ways. In words: multiply the number of tables by 4 and then add 2. In a flow diagram: input, then a times 4 box, then a plus 2 box, then output. As a number sentence: number of tables times 4 plus 2 equals number of chairs, or for 5 tables, 5 times 4 plus 2 equals 22. All three descriptions are equivalent, because they give the same output for every input.

To decide whether two descriptions are equivalent, test them with the same inputs. Add 2 and then multiply by 4 is a different rule. For 5 tables it gives 5 plus 2, which is 7, and then 7 times 4, which is 28, not 22. The order of the steps matters.

Some descriptions look different but are equivalent. Times 4 then plus 2 gives the same outputs as double, double again, then plus 2, because doubling twice is the same as times 4. Test with 5: double 5 is 10, double 10 is 20, and 20 plus 2 is 22.

When you write a number sentence for a pattern, say clearly what the input and the output stand for. Chairs and tables are different things, so the sentence must say which number is which.

The error museum, four exhibits. One: adding before multiplying, so 5 tables give 28 chairs instead of 22. Two: working backwards in the wrong order, dividing 30 by 4 first and getting a remainder. Three: using times 6 because one table seats 6, so 3 tables give 18 instead of 14. Four: testing a rule on one pair only, so times 5 seems to fit input 1, output 5, but input 2 gives 10, not 8.

The questions for this section are with you now: matching words, flow diagrams and number sentences, and checking whether two rules are equivalent.

# Part 2 — Simplifier

Now the same lesson again with the supper tables in Kimberley — plain words, same facts.

## Subtopic: Number In, Number Out

One table seats 6. Two tables seat 10. Three tables seat 14.

Rule: times 4, then plus 2.

Put in 5: 5 times 4 is 20, and 20 plus 2 is 22. Out comes 22.

Keep the rule machine in mind and try the questions for this part: finding outputs.

## Subtopic: Run It Backwards

30 chairs. Undo the last step first: 30 minus 2 is 28.

Then undo times 4: 28 divided by 4 is 7. So 7 tables.

To find a rule, look at how the outputs grow, then fix the start.

Hold the undo-in-reverse idea in mind and try this part's questions: inputs and rules.

## Subtopic: Same Rule, Different Clothes

Words: times 4, then add 2. Flow diagram: times 4 box, plus 2 box. Number sentence: 5 times 4 plus 2 equals 22.

Pocket summary of the lesson. A flow diagram takes an input, does the steps in order and gives an output. To find an output, follow the arrows. To find an input, start at the output, use the opposite operations and go in the opposite order. To find a rule, look at how the outputs grow and then adjust for the start. A rule can be written in words, as a flow diagram or as a number sentence, and they are equivalent when they give the same output for every input. The order of the steps matters, so test every rule.

Hold the test-it-with-inputs habit in mind and take the final questions of the lesson: one rule written three ways.
