Hey — if drawing graphs feels fiddly, here is the calm version: graphs are just pictures of the table, drawn fairly.

Pictograph? Write the key first, then divide each number by it.

Half a symbol for half the key: that is fine.

Bar graph? Start the scale at 0, count in equal steps, and use a ruler.

Every bar the same width. Then label everything.

Open the practice set and draw one bar at a time. You've got this!
