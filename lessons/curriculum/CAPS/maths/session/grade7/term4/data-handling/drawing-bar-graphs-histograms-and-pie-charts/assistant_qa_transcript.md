### subtopic_1 — Bar Graphs
**Assistant:** Why do the bars in a bar graph have gaps?

**Tutor:** Because the categories are separate things with no order or in-between values: there is nothing between taxi and bus. The gaps show that. In a histogram, which shows numbers that run on continuously, the bars touch instead, because one interval runs straight into the next.

### subtopic_2 — Histograms
**Assistant:** How do I tell whether to draw a bar graph or a histogram?

**Tutor:** Ask what is on the horizontal axis. If it is categories, like fruit or transport, draw a bar graph with gaps. If it is a measured number grouped into intervals, like marks, heights or times, draw a histogram with touching bars, because the number line continues from one interval to the next.

### subtopic_3 — Pie Charts
**Assistant:** When is a pie chart better than a bar graph?

**Tutor:** When you want to show how one whole is shared out, and compare each part with the whole. A pie chart instantly shows that walking is about a third of all learners. A bar graph is better for comparing the categories with each other exactly, or when there are many categories, because thin slices are hard to read.
