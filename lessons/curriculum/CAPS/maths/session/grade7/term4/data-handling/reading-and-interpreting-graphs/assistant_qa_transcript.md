### subtopic_1 — Reading Values From Graphs
**Assistant:** Why read the scale before the bars?

**Tutor:** Because the same bar height can mean very different numbers. If each grid line is 15, a bar five lines high means 75; if each line is 10, it means 50. Many reading mistakes come from assuming each line is one or ten. Checking the scale first takes a few seconds and prevents them.

### subtopic_2 — Interpreting Pie Charts and Histograms
**Assistant:** Can I compare two pie charts by slice size?

**Tutor:** Only if they represent the same total. A quarter slice of a 200-learner pie is 50 learners, but a quarter slice of a 40-learner pie is only 10. Pie charts compare parts within one whole very well, but comparing different pies needs the totals. Always look for the total before drawing conclusions.

### subtopic_3 — Misleading Graphs
**Assistant:** If the numbers on a misleading graph are correct, is it lying?

**Tutor:** It is not lying about the numbers, but it is misleading about what they mean. A cut-off axis shows real values, but the bar sizes suggest differences far bigger than they are. Since most people look at shapes rather than numbers, the impression is wrong. Reading the actual values and the axis start lets you see the truth.
