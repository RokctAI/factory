Forwards: follow the arrows in order and do each step. Backwards: start at the end, and undo each step in reverse — the last thing done is the first thing undone.

To find a hidden rule, look at how much the output jumps when the input goes up by one. That jump is what you multiply by. Then fix the start with an add or subtract.
