# Part 1 — Expert

This session covers determining input values, output values and rules for patterns and relationships using flow diagrams, tables and formulae. The anchor is a taxi fare: multiply the kilometres by 8 and add 12.

## Subtopic: Flow Diagrams: Finding Outputs

A flow diagram is a picture of a rule. Input values go in on the left, pass through one or more operators, and come out on the right as output values. Each input produces exactly one output.

The taxi fare machine: input the number of kilometres, multiply by eight, then add twelve. Output: the fare in rand.

Input three kilometres: three times eight is twenty-four, plus twelve is thirty-six. Fare R36. Input five: forty plus twelve, R52. Input ten: eighty plus twelve, R92. Input zero — a passenger who gets in and immediately out: zero plus twelve, R12, the fixed charge.

The order of the operators matters. Times eight then plus twelve gives thirty-six for three kilometres. Plus twelve then times eight would give fifteen times eight, 120 — a very different machine.

Flow diagrams can have any operators: add, subtract, multiply, divide, and even squaring. Input four into "square, then subtract one": sixteen minus one, fifteen.

The questions for this section are ready: run inputs through flow diagrams, in the right order.

## Subtopic: Working Backwards to Find Inputs

If you know the output, you can find the input by running the flow diagram backwards using inverse operations, in reverse order.

The fare was R76. How far did the passenger travel? The forward machine is times eight then plus twelve. Backwards: start at the output, undo the last step first — minus twelve: sixty-four. Then undo times eight — divide by eight: eight. The passenger travelled eight kilometres.

Check forwards: eight times eight is sixty-four, plus twelve is seventy-six. Correct.

Another: the fare was R140. Minus twelve: 128. Divided by eight: sixteen kilometres.

Sometimes the backward answer is not a whole number. A fare of R50: minus twelve, thirty-eight; divided by eight, 4,75 kilometres. That is a valid distance, so it is a valid input.

The inverse operations: plus undoes minus and minus undoes plus; times undoes divide and divide undoes times; square root undoes squaring.

Pause here for this section's questions: run machines backwards and check forwards.

## Subtopic: Finding the Rule From Inputs and Outputs

Sometimes you know inputs and outputs and must find the rule. Tables help.

A table for an unknown machine: inputs one, two, three, four; outputs five, eight, eleven, fourteen. Look at the outputs: they go up by three each time the input goes up by one. So the rule involves times three. Three times the input gives three, six, nine, twelve; the outputs are two more. Rule: multiply by three, then add two.

Check with input four: twelve plus two, fourteen. Correct. Now predict input ten: thirty-two.

A formula writes the rule with letters. If x is the input and y the output, the rule is y equals three times x plus two. For the taxi: fare equals eight times kilometres plus twelve, or f equals eight k plus twelve.

Rules can be found when inputs are not consecutive, but take care. Inputs two, five, ten; outputs seven, sixteen, thirty-one. From two to five the input rises three and output rises nine, so three per unit: times three. Three times two is six; output seven, plus one. Rule: times three plus one. Check ten: thirty plus one, thirty-one.

Here come the questions for this section: find rules from tables, write them as formulae and use them.

# Part 2 — Simplifier

The same taxi fare now, as a number machine you can run forwards and backwards. Same rule, everyday ride.

## Subtopic: The Taxi Fare Machine

Think of a taxi meter as a number machine. You feed it the number of kilometres, and it gives you the fare.

Inside the machine are two steps. First, it multiplies the kilometres by eight, because each kilometre costs R8. Then it adds twelve, because there is a R12 charge just for getting in.

Feed in three kilometres: three times eight is twenty-four, plus twelve, R36. Feed in five: forty plus twelve, R52. Feed in zero — you get in and change your mind: just the R12 charge.

The order matters. If the machine added twelve first and then multiplied by eight, three kilometres would cost R120! The R12 is only charged once, so it is added at the end.

A flow diagram is just a drawing of this machine: an input on the left, arrows through the steps, and an output on the right.

Your questions for this section are with you now: feed the number in, follow the arrows in order, and read the output.

## Subtopic: Running the Machine Backwards

A passenger paid R76. How far did she travel?

We know what came out of the machine. To find what went in, run the machine backwards — and undo each step.

The last step forwards was adding twelve, so undo it first: seventy-six minus twelve is sixty-four. The first step forwards was multiplying by eight, so undo it next: sixty-four divided by eight is eight. She travelled eight kilometres.

Check by running it forwards: eight times eight is sixty-four, plus twelve is seventy-six. Correct!

Now a mystery machine. You put in 1, 2, 3, 4 and get out 5, 8, 11, 14. What is inside? Each time the input goes up by one, the output goes up by three. So the machine multiplies by three. But three times one is only three, and we got five, so it must also add two. The mystery machine is: times three, then add two.

You can now use number machines forwards, backwards and even work out what is hiding inside. The last questions of the lesson are with you now: undo in reverse, or spot the jump and fix the start.
