## Question (2 marks)

(Context: ANNEXURE C shows the map with the tracked flight path of a GPS-fitted flamingo from area A to area E; the flight path does not pass over Queenstown.) Write down the probability that the bird flew directly over Queenstown.

**Note: ANNEXURE C is printed in the 2025 Special Answer Book, which is not in the archive; the fact that the flight path misses Queenstown is reconstructed from the marking guidelines. The memo answer is definitive.**

## Method

identify impossible event

## Memo working

(see marking guidelines) The tracked flight path on the map does not pass over Queenstown, so the event already failed to happen — it is impossible, and an impossible event has probability 0.

## Answer (per marking guidelines)

0 ; 0% ; Impossible
