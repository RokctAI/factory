## Question (2 marks)

One way to save money during winter is to wrap the geyser and waterpipes with a geyser blanket made of aerolite, an insulating material that can easily be cut (pictures show the steps of wrapping a cylindrical geyser in aerolite). Choose ONE of the following formulae that can be used to calculate how much aerolite is needed for the total surface area of the geyser only. Write only the letter (A-D). A: pi x radius^2 x height + 2 x pi x radius. B: pi x radius x height + length x width. C: 2 x pi x radius x height + 2 x pi x radius^2. D: 1/2 base x height.

## Method

select surface area formula

## Memo working

A geyser is a closed cylinder, so its total surface area has two parts: the curved (lateral) surface, which unrolls into a rectangle of area 2 x pi x radius x height, plus the two circular ends, each with area pi x radius^2, giving 2 x pi x radius^2. Total surface area = 2 x pi x radius x height + 2 x pi x radius^2 — option C. Option A mixes up the pieces (pi r^2 h is a volume, and 2 pi r is a circumference, not an area), option B mixes cylinder and rectangle formulas, and option D is the area of a triangle. (Memo: 2A correct formula.)

## Answer (per marking guidelines)

C
