## Question (2 marks)

A study recorded the time spent (in minutes) by 32 customers in a store. The recorded times include values such as 6, 8, 15, 25, 43, 67 and one value of 127. Give a reason why the value of 127 is considered to be an outlier in the data set.

## Method

explain outlier

## Memo working

An outlier is a value that lies far away from the rest of the data. Compare 127 with the next largest value in the set, which is 67: the value 127 is 60 minutes more than the second highest time in the data set, so it sits far outside the cluster formed by all the other values. (2O conclusion)

## Answer (per marking guidelines)

The value 127 is 60 minutes more than the second highest time in the dataset.
