## Question (2 marks)

ANNEXURE B includes the elevation map of the Leopard Trail Run route (height above sea level plotted against distance). On the Day 2 profile the axis labels read 864 m, 900 m, 975 m, 1 050 m and 1 173 m, with distance gridlines from 2,5 km up to 21,9 km; the highest point (about 1 173 m) occurs at the 12,5 km mark. Determine the number of kilometres John had run when he reached the highest point above sea level on Day 2.

## Method

read value from elevation map

## Memo working

On an elevation map the height above sea level is on the vertical axis and the distance run is on the horizontal axis. Find the highest peak of the Day 2 profile — it reaches about 1 173 m — then read straight down to the distance axis: the peak sits on the 12,5 km gridline. So John had run 12,5 km when he reached the highest point. (Memo: 2RT correct distance.)

## Answer (per marking guidelines)

12,5 km
