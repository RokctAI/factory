Hey, it's Bianca — if a table of numbers makes your stomach drop, I promise you this topic is smaller than it looks. There are only three tests, and you run them in the same order every single time. It is a checklist, not a talent.

Test one: subtract. Take each value away from the next. Same answer every time? Linear — something fixed plus something per unit, straight-line graph. Test two: multiply. Multiply each pair across the table. Same answer every time? Inverse proportion — the bakkie shared further. Test three: divide. Divide each value by the one before it. Same answer every time? Constant ratio — the stokvel multiplying itself. Subtract, multiply, divide. That is the whole diagnosis.

The bit that trips people is going backwards. A bill arrives and you must find the usage. Undo the rule in reverse order: take the fixed charge off FIRST, then divide by the rate. If you divide the whole bill by the rate you have quietly charged yourself for water you never used, and the marker sees it immediately. Say it to yourself: fixed off first, then divide.

Your mark-protecting habit for this topic is showing the substitution. Do not do it in your head. Write the formula, then write the numbers going into it, then the answer. Even when the final answer is wrong, that written substitution earns marks — a bare number cannot.

And finish with a sentence. Not "30". Rather: "the household used 30 kilolitres that month." Units on, question answered, done.

Three tests, fixed part off first, substitution shown, answer in a sentence. That is genuinely all of it. You've got this!
