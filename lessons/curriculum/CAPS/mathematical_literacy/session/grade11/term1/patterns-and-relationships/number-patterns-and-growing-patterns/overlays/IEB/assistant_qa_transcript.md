**Bianca:** Before you move on — a few questions that come up constantly with this topic. First: how do you tell the three families apart quickly when the numbers look nothing like the examples?

**Tutor:** Run the same two tests in the same order, whatever the numbers look like. Test one: subtract neighbours. Write the gap between every pair of consecutive terms. If the gaps all agree, you have a constant difference pattern and the diagnosis is finished — the shared gap is your step. If the gaps disagree, study how they disagree before doing anything else. Gaps that grow by the same amount each time — two, three, four, five — announce a growing-step pattern, the stacking family. Gaps that seem to double or triple send you to test two: divide neighbours. Divide each term by the one before it; if that answer repeats, you have a constant ratio pattern and the repeated answer is your multiplier. The order matters because subtraction is faster and catches the commonest family first, and the shape of a failed subtraction usually names the family on its own. Two tests, run in order, and every list a question can print falls into one of three drawers inside a minute.

***

**Bianca:** Next: in Mathematical Literacy, do we ever need the nth-term formula, or is extending a table always enough?

**Tutor:** The table is enough, and it is the intended method. This subject tests whether you can use patterns inside real situations — tariffs, stacks, schedules — not whether you can build algebraic machinery. Every pattern question you will face can be answered by writing the terms into a table and extending carefully to the position asked for: term by term for a constant difference, multiplication by multiplication for a ratio, running total by running total for a stack. What does earn extra credit is describing the rule in words — add eight each time, triple each day, each row adds one more — so practise saying rules as sentences. Where learners burn time is extending blindly to faraway positions, so borrow one shortcut for the stacking family alone: to add one up to eight, pair the ends — one with eight, two with seven, three with six, four with five — four pairs of nine gives thirty-six. Use the table as your method and the pairing as your check, and full marks need no formula at all.

***

**Bianca:** Third: the missing-middle-term questions. People find the step, fill the blank, and still lose the mark. What goes wrong?

**Tutor:** They walk to the blank from one side only, and question-setters count on it. Suppose the list reads seventeen, twenty-five, blank, forty-one. A rushed candidate finds the step of eight, adds it to twenty-five, writes thirty-three and moves on — correct this time, but only by luck, because forty-one was never consulted. Setters love lists where a careless step survives the first check and collapses on the second: if the true step had been nine, the blank from the left would be thirty-four, but forty-one minus nine is thirty-two, and that disagreement shouts that the step itself was wrong. So make the both-sides walk a ritual. Add the step to the term before the blank; subtract the step from the term after it; only an answer both walks agree on goes in the answer book. It costs ten seconds, it catches wrong steps as well as wrong arithmetic, and it turns the shakiest question type in this topic into a guaranteed mark.

***

**Bianca:** Last one: the stacked-rows question — what exactly must go in the answer book to collect every mark?

**Tutor:** Show the build, then land on the total with its unit. The marker wants to see that you understood the structure — one object in the first row, one more in each row after — and that you accumulated it correctly. The cleanest presentation is the two-column table: row number down the left, total so far down the right. One, one. Two, three. Three, six. Four, ten. Five, fifteen. Six, twenty-one. Seven, twenty-eight. Eight, thirty-six. Every line is a visible small addition, so nothing can hide even under time pressure. Then write the sentence the question actually asked for: the display uses thirty-six cans — the number and the thing being counted, together. If thirty spare seconds exist, run the pairing check beside the table so a slip cannot survive. And before any of that, underline what is being counted: the row or the whole stack. Eight is the eighth row; thirty-six is the display. Most marks lost on this question type come from correct arithmetic attached to the wrong count.
