**Student:** How do I know which line is Option A and which is Option B if the graph doesn't label them nicely?

**Thandi:** Use the starting points — they're like name tags! Ask: what would each option cost at ZERO usage? Option A has no fixed charge, so zero usage costs R0 — its line must start at the origin. Option B charges R150 before you use anything, so its line starts at R150 up the vertical axis. The intercept literally *is* the fixed charge, so match each line's starting height to each option's fixed fee and they identify themselves. Works on every tariff, contract and membership graph you'll ever meet.

***

**Student:** I don't really get what "gradient" means here. In maths class it was just a number.

**Thandi:** Here the number gets a job! On a cost graph, the gradient is the *price per unit* — how many rands the bill climbs every time you use one more kilowatt-hour. Option A climbs R2 for every unit; Option B climbs R1,50. That's why A's line looks steeper — every step to the right costs more on A. So when a question says "explain what the steeper gradient means," they want: "Option A charges more per unit — R2,00 per kWh versus R1,50 — so its cost rises faster as usage increases." Gradient = the speed your money leaves you!

**Student:** At 450 kWh I said Option B is cheaper and got 2 out of 3 marks. What was the missing mark?

**Thandi:** Almost certainly the *evidence*. "B is cheaper" is a claim; full marks want the receipts: A costs 450 × R2,00 = R900, B costs R150 + 450 × R1,50 = R825, so B is cheaper *by R75*. Name both totals and the difference. It feels like extra work, but comparison questions in Maths Lit almost always carry a mark for the calculated values and a mark for the explicit comparison. Claim, calculate, compare — three Cs, three marks.

**Student:** Is break-even always where the lines cross? What if there are three options on the graph?

**Thandi:** Great forward-thinking! Break-even is between a *pair* of options — it's the usage where those two cost the same. With three lines you get up to three crossings: A-with-B, A-with-C, B-with-C, and each crossing hands the "cheapest" title from one option to another. The winning strategy stays the same: at any usage, the *lowest* line at that point is the cheapest option. Run your finger up from the usage value and the first line you hit wins. The crossings just mark where the leadership changes — like relay runners passing the baton.
