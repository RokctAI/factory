### subtopic_1 — What a Grid Is
**Assistant:** Why do we write the letter first and not the number?

**Tutor:** It is a rule that everyone agrees to follow, so that nobody gets confused. If some people wrote C3 and others wrote 3C, it would not matter much on a small map, but on bigger maps with more complicated grids, mixing the order could send people to the wrong place. In an alpha-numeric grid, the letter tells you the column, and the number tells you the row. Putting the letter first means you always start by going along the top, then down the side. Once everyone uses the same order, a grid reference means exactly the same thing to every person who reads it. You will meet the same kind of rule in other places. In a spreadsheet on a computer, every box, called a cell, has a name like B7, letter first and then number. Later, in Grade 5 and Grade 6, you will learn about a different kind of grid that uses numbers on both sides, and it has its own rules about order too.

### subtopic_2 — Reading a Grid Reference
**Assistant:** How do pilots and ships find places, if they do not use letters and numbers?

**Tutor:** They actually do use a kind of grid, but it covers the whole Earth. Mapmakers have drawn imaginary lines over the whole globe. Some lines run from the North Pole to the South Pole, and others run around the Earth, parallel to the equator. These lines make a giant grid. Every place on Earth can be given an exact position using numbers from these lines, called latitude and longitude. Pilots, ship captains, and the maps on cell phones all use them. A cell phone uses signals from satellites, called GPS, to work out its position on this world grid, and then shows you on the map. You will learn about latitude and longitude in later grades. The alpha-numeric grid you are learning now is the first step, and it works in exactly the same way: a column and a row meet at one place. If you understand C3, you are already on your way to understanding the grid that pilots use.

### subtopic_3 — Giving a Grid Reference
**Assistant:** What do I do if a place is right on the line between two blocks?

**Tutor:** That can happen, especially with things like roads, rivers or a building drawn right on a grid line. Here are some ways to deal with it. First, look closely to see which block most of the place is in. If more of it is in C2 than in C3, give C2. Second, look for the symbol or the label. If the symbol is just inside one block, use that block. Third, if it really is half and half, you can give both blocks, such as C2 and C3. In a test, it is a good idea to say which block you chose and why, if there is space. Teachers usually choose places that are clearly inside one block for grid reference questions, so this does not happen often. But on real maps, long things like rivers and roads cross many blocks, and that is fine, because the grid is there to help you find the right area, not to fit everything into one square.
