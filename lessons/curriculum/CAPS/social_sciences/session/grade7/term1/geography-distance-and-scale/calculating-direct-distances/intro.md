How far is Bloemfontein from Kimberley as the crow flies? Today we learn to answer questions like this from a map. A direct distance is the straight-line distance between two places. We first estimate it quickly using the scale, then measure it accurately with a ruler and calculate the real distance with a word scale or a line scale. We set out the working in clear steps, check whether the answer is sensible, and learn why the straight-line distance is almost always shorter than the distance you would actually travel.
