Hey, it's Bianca — two-body questions look like double the work, and that is exactly the wrong way to see them. They are not two problems. They are one easy problem followed by one very short one, and once you know the order you will start hoping for them in the paper.

The order is everything. Move one: pretend the two objects are glued into a single object. Add the masses. Add up only the forces from outside — the push, the friction, the hanging weight — and completely ignore the string. Divide, and you have the acceleration. Move two: pick ONE object, preferably the one with fewest forces on it, write Newton's second law for that object alone with the acceleration you just found, and the tension drops out in a line.

Why can you ignore the string in move one? Because it pulls one body forward and the other backward with exactly the same size, so inside the combined object those two pulls cancel. That is not a shortcut somebody invented — it is the reason the method is correct, and if you can say that sentence in a question you have earned an explanation mark.

The habit that protects you is a small piece of discipline: draw two separate free-body diagrams, one per body, side by side, before you write a single equation. Label the tension with the same symbol on both. Then when you get to move two, only the arrows on that one diagram may enter the equation. The most expensive error in this topic is putting the friction of BOTH crates into ONE crate's equation, and two separate drawings make that almost impossible.

One more thing to expect, because it feels wrong the first time. When a mass hangs on a string and is falling, the tension is always LESS than that mass's weight. It has to be — if the string pulled with the full weight, the forces would balance and nothing would fall. Tension only equals the weight when the acceleration is zero. If your answer comes out with the tension bigger than the hanging weight, you have a sign error somewhere.

Same acceleration, cancel the tension, two diagrams, one body at a time. That is a whole exam question in four short instructions. You've got this!
