Today we are lifting vectors off the straight line and onto the full two-dimensional plane, where a force may point in any direction at all. The session builds the one procedure that answers every such exam question: resolve each vector into perpendicular components with cosine and sine, add the x-parts and y-parts in separate columns, then rebuild a single resultant using Pythagoras for the magnitude and the inverse tangent for the direction. We will work the standard four-force problem end to end, and name the traps — the swapped sine and cosine, the dropped minus sign, and the calculator left in radian mode. This method returns in Newton's laws on inclines and in electrostatics, so it is worth owning completely.
