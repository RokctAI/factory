## Question (2 marks)

Multiple choice: Which of the following statements ALWAYS apply to compounds that are structural isomers of one another? (i) They belong to the same homologous series. (ii) They have the same structural formula. (iii) They have the same molecular formula. A (iii) only B (i) and (iii) only C (i) and (ii) only D (i), (ii) and (iii)

## Method

multiple choice

## Memo working

(see marking guidelines) Structural isomers are, by definition, compounds with the same molecular formula but different structural formulae. So statement (iii) is always true, and statement (ii) is never true — if the structural formulae were the same, they would be the same compound, not isomers. Statement (i) is not always true either: functional isomers (for example an aldehyde and a ketone with the same molecular formula) are structural isomers that belong to different homologous series. Only (iii) always applies.

## Answer (per marking guidelines)

A
