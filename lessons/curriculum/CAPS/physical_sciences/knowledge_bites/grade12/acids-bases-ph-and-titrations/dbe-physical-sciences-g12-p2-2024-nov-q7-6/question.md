## Question (5 marks)

The above K2CO3 solution used in the titration was prepared by completely dissolving 6,525 g of the hydrated potassium carbonate, K2CO3·xH2O, in 600 cm³ water. Calculate the value of x in the formula K2CO3·xH2O. (From QUESTION 7.5: c(K2CO3) = 0,0622 mol·dm⁻³.)

## Method

hydrate molar mass calculation

## Memo working

POSITIVE MARKING FROM QUESTION 7.5. OPTION 1: c = m/MV: 0,0622 = 6,525/(M x 0,6); M = 174,84 g·mol⁻¹. Set the molar mass of K2CO3·xH2O equal to 174,84: 2(39) + 12 + 3(16) + x(18) = 174,84; x = 2. OPTION 2: n(K2CO3) in 600 cm³ = (0,0622)(0,6) = 0,0373 mol; 0,0373 = 6,525/(138 + 18x); x = 2. OPTION 3: m(K2CO3) = 0,0373 x 138 = 5,147 g; m(H2O) = 6,525 – 5,147 = 1,378 g; n(H2O) = 1,378/18 = 0,0766 mol; the ratio 0,0373 : 0,0766 gives x = 2.

## Answer (per marking guidelines)

x = 2
