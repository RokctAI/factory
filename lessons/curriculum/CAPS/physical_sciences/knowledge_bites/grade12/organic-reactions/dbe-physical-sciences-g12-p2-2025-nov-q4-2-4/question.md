## Question (3 marks)

A compound with the formula C10H22 undergoes a cracking reaction according to the equation: C10H22(ℓ) → 2X(g) + C4H10(g). The mixture of the two products is bubbled in bromine water, Br2(aq), in a darkened room. Which compound, X or C4H10, reacts faster with Br2(aq)? Explain the answer.

## Method

reactivity saturation reasoning

## Memo working

(see marking guidelines) X is C3H6 (propene), an unsaturated alkene with a double bond, while C4H10 (butane) is a saturated alkane. The alkene reacts with bromine by fast addition across the double bond, needing no light; the alkane can only react by substitution, which needs UV light and is slow — and the room is darkened. So X reacts faster.

## Answer (per marking guidelines)

X / C3H6 / propene. X is unsaturated / has a double bond / is an alkene; X undergoes addition (OR alkenes are more reactive than alkanes / unsaturated compounds react faster than saturated compounds / addition reaction is faster than substitution / addition reaction does not need UV/light).
