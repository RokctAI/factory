## Question (2 marks)

Multiple choice: Which ONE of the following compounds has hydrogen bonds between its molecules? A CH3CH2CHO B CH3COOCH3 C CH3CH2CH2OH D CH3COCH3

## Method

multiple choice

## Memo working

(see marking guidelines) Hydrogen bonds form between molecules only when a hydrogen atom is bonded directly to N, O or F. Option A (CH3CH2CHO, an aldehyde) and option D (CH3COCH3, a ketone) have a C=O group but no O–H bond; option B (CH3COOCH3, an ester) also has no O–H bond. Only option C, CH3CH2CH2OH (propan-1-ol), contains a hydroxyl O–H group, so only its molecules can hydrogen bond with one another.

## Answer (per marking guidelines)

C
