## Question (2 marks)

The costs that will always decrease when production increases, is referred to as … cost.

A average
B average variable
C total
D average fixed

## Method

multiple choice recall

Think about which cost is spread ever thinner as output grows. Fixed costs, like rent, stay the same in total no matter how much is produced, so dividing the same rand amount by more and more units means average fixed cost falls continuously. Average variable cost and average cost eventually rise again as diminishing returns set in, and total cost always rises — only average fixed cost always decreases.
