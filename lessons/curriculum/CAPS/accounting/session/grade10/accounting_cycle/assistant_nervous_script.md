Hey, it's Thandi — take a breath for a second.

I know six stages sounds like a lot to memorise, especially when each one has its own strange name like "trial balance" and "final accounts". But here's the secret: you don't have to memorise it like a poem. Each stage exists because the one before it needs it — a slip becomes a journal entry, journal totals become ledger balances, balances become the trial balance. If you remember the *story* of one cash sale travelling through, the order takes care of itself.

You've actually done half of this already in Grade 8 and 9 — source documents and journals are old friends. The new part is just seeing how they connect. Try the practice questions now, and if you get an order question wrong, don't stress: just ask yourself "what does this stage need from the one before it?" and the answer will click. You've got this.
