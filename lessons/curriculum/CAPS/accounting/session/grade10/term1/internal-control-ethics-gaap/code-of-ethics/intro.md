Today we study the code of ethics — the formal statement of values that binds every party in the financial environment, and the seven characteristics the syllabus names: leadership, discipline, transparency, accountability, fairness, sustainability and responsible management. Financial information only has value if it can be trusted, so ethics is not a soft add-on to Accounting; it is the precondition for the whole discipline. Examiners test it with scenarios, demanding that you name the characteristic at stake and argue the link, so we will define all seven for marks, work three scenarios at examination depth, and build the four-move method that structures a full answer. By the end, a code-of-ethics question becomes marks you collect with a method, not an opinion you improvise.
