Today we add a new drawing skill to the oblique projection you learnt in Grade 7. Isometric projection shows an object in 3D with all three axes drawn at equal angles: the vertical stays vertical, and the two horizontal directions slope up at 30 degrees to the left and right. Drawn on an isometric grid of dots or triangles, it gives a clear, balanced picture in which every edge along an axis can be measured. We learn the rules, practise on simple boxes and then draw the PAT structure to scale with dimensions. By the end you will be able to draw any rectangular object so that it looks solid and can still be measured.
