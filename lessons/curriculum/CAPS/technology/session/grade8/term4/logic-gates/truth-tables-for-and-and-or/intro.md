Today we write down a gate completely. A truth table lists every possible combination of inputs and the output each one produces, so that a gate's whole behaviour sits in a few rows that anyone can check. We learn how to set a table up so that no combination is missed, we fill in the AND and OR tables and test every row with real switches and a lamp, we compare the two tables to see exactly how the gates differ, and we practise the reverse skill of reading a table and saying which gate, or which switch circuit, it describes. By the end you will be able to construct a truth table for any two-input gate, verify it on the bench, and use it as the design document for the panic button next week.
