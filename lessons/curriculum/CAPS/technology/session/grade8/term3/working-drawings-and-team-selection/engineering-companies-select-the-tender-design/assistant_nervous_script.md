Hey — if being judged by other teams feels scary, remember that every real engineer's design gets reviewed, and the review is a gift.

When you review: score each rule 0 to 3 against their table, name the strongest feature, the biggest risk, one suggestion. Talk about the drawing, never the person.

When reviewed: read all the sheets first, sort them, do not argue. The sting that is right is the most useful line.

Then choose, and write why.

Open the practice set and rewrite "this tower will fall over" as a comment against a specification. You've got this!
