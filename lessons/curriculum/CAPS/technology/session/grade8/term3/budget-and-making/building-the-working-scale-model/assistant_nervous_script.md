Hey — if building a whole tower with a motor in two lessons feels like too much, you have a flow chart that already says what to do next.

Saw in a bench hook, drill clamped, knife along the rule, eyes covered. One person on the switch.

Base square. Faces flat with a diagonal in every rectangle. Stand them, check plumb, then lock with the last diagonals. Back-leg cut to fit. Sheave on top.

Gear plate square to the rope, train free by hand, collars on. Then test with the stopwatch and write the numbers down.

Open the practice set and say which test comes first and why. You've got this!
