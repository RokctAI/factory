Hey — if designing a package feels like you need to be an artist, here is the calm version. It is a checklist, not a talent.

Five jobs: protect, contain, inform, convenient, sell. Ask which matter most for your product.

Then ask about the product: fragile? heavy? liquid? spoils? dangerous? how stored? That decides the shape.

Then pick a material whose properties match: card for dry and light, film for waterproof, glass for a total barrier.

Write one line for each choice: this property meets this need.

Open the practice set and list the five jobs for a bar of soap in order. You've got this!
