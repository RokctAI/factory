Today we sharpen the drawing conventions that every working drawing depends on. Grade 8 used dark, feint and dashed lines; Grade 9 adds the wavy break line and the chain line for centres and sections, so there are five line types to know. We then revise scale, so that a seven-metre ramp fits on an A4 page, and the rules of dimensioning, so that a builder can read every size without a ruler. By the end you will be able to name each line type, choose a scale and dimension a simple drawing correctly.
