The item you specified two weeks ago now has to be drawn so that someone else could make it. The language for that is first angle orthographic projection, which you have used since Grade 7: a front view, a top view below it and a side view beside it, drawn to scale with the right line types, dimensions and a title block. This session recalls the rules, then applies them to a plastic item with the features moulding needs, even wall thickness shown in section, draft on the sides, rounded corners, ribs and holes. It ends with a checklist for marking your own drawing before you hand it in, since a drawing that cannot be read cannot be made.
