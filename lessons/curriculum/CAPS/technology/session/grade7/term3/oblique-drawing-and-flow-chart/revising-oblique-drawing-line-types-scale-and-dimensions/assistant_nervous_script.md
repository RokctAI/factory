Hey — if oblique drawing feels like a term-one memory, here is the calm version. Draw the front flat. Draw 45 degree lines back from each corner, half as long as the real depth at your scale. Join them up.

Thick for edges, thin for guides, dashed for hidden, chain for centres. Scale 1:2 is half size, but write real sizes.

Each size once, thin lines, arrowheads, number above the line, title block at the bottom.

Open the practice set and picture the box growing out of the page. You've got this!
