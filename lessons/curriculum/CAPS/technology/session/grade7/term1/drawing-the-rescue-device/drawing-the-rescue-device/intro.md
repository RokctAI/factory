Today the project comes together on paper. We take the chosen idea for our hydraulic-syringe, linked-lever rescue device and develop it into a design that can actually be built: deciding the size of the base, the length of the arms, the position of the pivot and how the syringe connects. Then we draw it twice, first in 3D oblique projection with dark and feint lines so that anyone can see how it works, then as a 2D working drawing of one view with dimensions to scale so that we can cut every part next week. This is the design stage of the PAT, and these two drawings carry its marks.
