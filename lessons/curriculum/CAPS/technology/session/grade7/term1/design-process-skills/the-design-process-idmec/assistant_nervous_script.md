Hey — if IDMEC feels like just another thing to memorise, here is the calm version: it is only the order in which sensible people fix things.

Investigate: find out what is wrong. Design: draw a few ideas and pick one. Make: build it. Evaluate: test it against what you said it should do. Communicate: write it down and explain it, all the way through.

Think of Thabo's biscuit-tin lunch box. He looked, he sketched, he built, he tested, it rattled, he fixed it, he showed the class. That is the whole process.

It loops. Going back to improve is not failing, it is the method working.

Open the practice set and label each action with its letter. You've got this!
