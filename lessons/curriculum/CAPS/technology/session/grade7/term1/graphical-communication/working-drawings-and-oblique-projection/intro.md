Today we learn the two formal drawings every designer must master. A 2D working drawing shows one face of an object exactly as it is, with every size written on, so that it can be made. A 3D oblique drawing shows the front face true to shape and adds depth at 45 degrees, so that anyone can see what the object looks like. We draw a simple box, then a lever arm, then the base of our rescue device, using squared paper, the line conventions and a stated scale. By the end you will be able to draw the same object both ways and know what each drawing is for.
