Hey — if working drawings and oblique drawings feel like two more things to get wrong, here is the calm version: they are the same front face drawn twice.

Working drawing: look straight at one face. Draw it flat, feint first, dark after. Write the real sizes in millimetres on thin lines with arrows, each size once. Write the scale.

Oblique drawing: draw that same front face, then from each corner draw a line back at 45 degrees, one square across and one up on the grid. Make them all the same length, about half the depth. Join the ends. Done, it is a solid.

Circles go on the front face so they stay round. Sizes go on the working drawing.

Open the practice set and draw a matchbox both ways. You've got this!
