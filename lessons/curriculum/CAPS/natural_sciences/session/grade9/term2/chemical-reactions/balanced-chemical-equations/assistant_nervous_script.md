Hey — balancing equations feels like a puzzle at first, but it is really just careful counting with a fixed routine. Here is the calm version.

Why balance? Atoms are never created or destroyed, so every atom on the left must appear on the right.

The routine. Write the word equation. Swap in correct formulae: oxygen gas is O2, hydrogen gas is H2. Draw a table: element, left, right. Fix one element at a time by changing only the big numbers in front. Start with the elements that appear once on each side; leave oxygen and hydrogen for last. Recount after every change, because a big number multiplies the whole formula. Finish with the smallest whole numbers.

Example: CH4 + O2 → CO2 + H2O. Carbon is fine. Hydrogen is 4 and 2, so make it 2H2O. Oxygen is now 2 and 4, so make it 2O2. Final: CH4 + 2O2 → CO2 + 2H2O.

Never change a little number. Changing H2O to H2O2 makes a different substance.

When oxygen comes in 2s and 3s, use 6, as in 4Fe + 3O2 → 2Fe2O3.

Open the practice set and do one element at a time. You've got this!
