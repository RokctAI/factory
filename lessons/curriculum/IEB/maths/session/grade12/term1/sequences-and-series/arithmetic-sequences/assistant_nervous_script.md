Hey, it's Mandy — if the letters a, d and T n started flying past and your stomach dropped, breathe. This lesson is not a memory test. An arithmetic sequence is just a staircase with equal steps, and every single question is one of three things you can ask about a staircase.

One: is it a real staircase? Subtract each term from the next. Same gap all the way: arithmetic. One odd gap: not. Subtract in order — later term minus earlier — so a downward staircase shows its negative d without confusing you.

Two: what number sits on step n? That is T n equals a plus n minus one times d. The n minus one only says the bottom step needs no climb — step nine took eight jumps. Build the formula, then test it on a step you can already see. If it reproduces term four, trust it for term two hundred.

Three: which step carries a given number? Set T n equal to the number and solve. A natural number n names the position. A decimal n means the number is not there — write that sentence, because the sentence is the answer. Only the reach-a-target word problems round up, and only because the target gets passed mid-step.

For an x hiding in the terms: middle minus first equals last minus middle, solve, substitute back and look at the real gaps. For inserted means, think fence posts — four posts between two corners make five spaces, always one more space than posts.

Same gap, start plus jumps, n comes out whole. That is the entire lesson, and the practice questions waiting for you now use nothing else. You've got this!
