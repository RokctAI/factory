Today functions stop being pictures and become precise machinery. We pin down the formal definition — one input, exactly one output — and then ask the grade twelve question: when can a function be run backwards? The swap of x and y builds the inverse, the line y equals x holds the mirror that reflects every graph onto its reverse, and the horizontal line test warns us when an inverse will refuse to be a function. When it does refuse, we perform the repair the examiners love to ask about: restricting the domain to a single arm so the reversal answers with one voice.
