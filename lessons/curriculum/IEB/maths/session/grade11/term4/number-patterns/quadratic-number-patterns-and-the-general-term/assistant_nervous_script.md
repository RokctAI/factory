Hey, it's Bianca — if quadratic patterns feel like last year's patterns that suddenly grew teeth, breathe, because the whole topic runs on one table and three small facts, and every skill it borrows is already yours.

The table first. Write the terms, write the gaps, write the gaps of the gaps. If the first gaps repeat, it is the linear kind from grade ten — done. If the SECOND gaps repeat, it is quadratic, and that steady number at the bottom is your first prize: halve it, and a is found.

Then the other two facts, in order. The very first gap equals 3a plus b — you already have a, so b drops out. The very first term equals a plus b plus c — you have both, so c drops out. a, then b, then c, each answer feeding the next. Assemble Tn, then spend ten seconds testing it on a term you never used. That small test is the difference between knowing and hoping.

Using the formula is driving a machine with two gears. Forward gear: feed in a position, receive the term — the fiftieth term without listing forty-nine others. Reverse gear: given a value, set the formula equal to it and solve the quadratic — your factorising from last year, back on shift. Just remember positions are parking bays: whole and positive. Reject the negative root in writing, and when the discriminant refuses to be a perfect square, say the honest sentence: that number is never a term.

Picture patterns are the same machine in work boots: count the first figures, difference, build, and answer in bricks and pads, not bare numbers.

Gaps, gaps of gaps, halve the bottom, three screws in order, test on an unseen term. That is the entire topic — one table plus a quadratic equation you have solved a hundred times. You've got this!
