Today we are running the data cycle from start to finish — collecting, organising and summarising data, using a real taxi-rank study where fifteen queueing times must convince a queue marshal how to spend the association's money. You will learn to pose a question that can actually be measured, to sort raw values into a tally and a frequency table, and to calculate the mean, median, mode and range with full working. Most importantly, you will learn which summary answers which question — the interpretation step where the marks that separate a pass from a distinction are earned.
