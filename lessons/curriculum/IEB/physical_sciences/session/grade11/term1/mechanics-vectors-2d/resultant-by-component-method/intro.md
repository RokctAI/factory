Today vectors leave the straight line behind and take up residence on the full two-dimensional plane, where a force may lean at any angle it chooses. This session builds the one procedure that answers every such question: resolve each vector into perpendicular components using cosine and sine, total the x-parts and y-parts in separate columns, then reassemble a single resultant with Pythagoras for the magnitude and the inverse tangent for the direction. We work a four-force problem from start to finish and name the classic traps — sine and cosine swapped, a minus sign dropped, and a calculator secretly set to radians. The same method carries you through inclined planes and two-dimensional electrostatics later this year, so it deserves to be owned completely.
