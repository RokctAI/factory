# Audit Rules — Forbidden Questions

Every new episode is audited against:

1. The master thread — can it be placed on the thread in 00_series_index.md?
2. The six-section structure — are all sections present and complete?
3. Cross-references — do the linked files exist? Are the connections accurate?
4. Translation notes — are key terms verified in Hebrew/Greek original?
5. The existing episode standard — does it match the depth and precision of the existing 15?

Audit chain:
Episode section by section -> Thread alignment -> Cross-reference accuracy -> Translation verification

If any check fails, flag specifically. Do not rewrite what is not broken.
Maximum three revision attempts. If an episode fails three audits flag for human review.
The agent that wrote the episode does not audit it.
