# Pedagogy Rules — lesson.physical_sciences

- CAPS alignment: teach only what the job card's grade/topic/subtopic
  covers in the South African CAPS curriculum; flag rather than smuggle in
  out-of-scope techniques.
- Respect the card's `prior_knowledge` line: everything beyond it must be
  taught, nothing within it re-taught at length.
- Grade-appropriate language: define every new term the first time it is
  used; Big John lessons additionally ground each abstract step in a
  concrete, real-world picture first.
- Worked examples before practice: the card's example problem is solved
  completely in the script before any MCQ asks the student to do the same
  move.
- Mandy materials (nervous-student script, post-session Q&A transcript)
  answer the questions a struggling student would actually ask — mistakes,
  "why did we do that step", "when do I use this" — in plain, reassuring
  language.
- Accuracy is gated by a human: Level 4's reviewer approves content
  accuracy before anything proceeds (supacharge-tech.md §4 step 3). Write
  for that reviewer — show working, cite the CAPS topic, keep answer keys
  auditable.
