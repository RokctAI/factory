# Script Rules — Documentary

Documentaries must follow this exact format:

1. **Scene Heading:** Defines Location and Time.
2. **Visuals (Left Column / Primary):** What is seen on screen.
3. **Audio/Narration (Right Column / Secondary):** What is heard (interviews, VO, sound design).

## Rules
1. Never describe what cannot be filmed or animated.
2. Keep Voice Over (VO) conversational, not purely academic.
3. Let visuals carry the emotional weight where possible.
